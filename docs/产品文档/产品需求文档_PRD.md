## 一、项目概述

### 1.1 产品定位

爆文猎人是一款面向内容创作者的**多平台爆文采集→分析→改写一体化工具**。帮助用户从小红书、公众号、头条等平台快速发现热点内容，自动解析爆款基因，并一键改写为符合目标平台风格的原创文章。

**一句话描述**：采集热点、拆解爆款、跨平台改写，让内容创作从0到1只需10分钟。

### 1.2 背景与痛点

| 痛点 | 现状 | 爆文猎人的解法 |
|------|------|----------------|
| 找热点慢 | 逐个刷平台，靠直觉判断 | 多平台聚合采集，热度评分排序 |
| 不知道为什么爆 | 只看数据，不懂拆解 | 自动提取标题公式、情绪标签、结构模板 |
| 跨平台改写难 | 手动调整语气/格式/emoji，耗时 | 一键按7个平台规则分别输出 |
| 素材零散 | 收藏夹/笔记/截图散落各处 | 统一素材库，标签+搜索+归档 |
| 不追趋势 | 不知道热点在涨还是退 | 趋势图表+数据看板 |

### 1.3 目标用户

| 用户类型 | 画像 | 核心诉求 |
|----------|------|----------|
| 自媒体新人 | 刚起步，不知道写什么 | 找热点选题，快速出稿 |
| 多平台运营者 | 同时运营2个以上平台 | 一篇素材多平台改写 |
| 内容团队负责人 | 管理多个账号，需要选题规划 | 热点趋势监控，数据驱动选题 |

## 四、核心用户流程

### 4.1 主流程：从采集到创作

```
用户打开首页
  → 浏览今日热点 / 点击"手动采集"
  → 输入关键词，选择平台，开始采集
  → 查看采集结果列表，按评分排序
  → 点击某条素材，查看爆款分析
  → 点击"以此为素材创作"
  → 进入创作工坊，选择目标平台
  → 调整改写参数，点击"一键生成"
  → 查看/编辑各平台版本
  → 导出或复制
```

### 4.2 文档上传流程

```
用户打开采集中心 → 点击"上传文档"
  → 拖拽或选择文件（支持 TXT/MD/DOCX/PDF/HTML）
  → 系统解析文档，提取正文内容
  → 判断文档数量：
     ├─ ≥10篇 → 自动进入爆款分析流程
     └─ ＜10篇 → 弹窗提醒"文档数量较少，分析结果可能不够准确，是否继续？"
        ├─ 用户确认 → 继续分析
        └─ 用户取消 → 返回上传界面，可继续补充文档
  → 分析完成后自动归档至素材库
```

### 4.3 素材管理流程

```
用户进入素材库
  → 按标签/日期/平台/评分筛选
  → 浏览素材卡片
  → 点击进入详情
  → 添加/编辑标签
  → 收藏或批量导出
```

### 4.4 定时采集流程

```
用户进入设置→采集计划
  → 新建计划：名称+关键词+平台+频率（每日/每周）+时间
  → 保存计划
  → 系统按计划自动执行采集
  → 采集完成后首页看板更新
  → 用户可在采集日志中查看执行记录
```

## 五、非功能需求

### 5.1 性能

| 指标 | 要求 |
|------|------|
| 采集响应 | 手动采集结果10秒内返回 |
| 改写生成 | 单平台改写15秒内返回，7平台全量60秒内 |
| 页面加载 | 首屏1.5秒内 |
| 并发支持 | 单用户场景，无需高并发 |

### 5.2 可用性

| 指标 | 要求 |
|------|------|
| 浏览器兼容 | Chrome / Edge / Safari 最新2个版本 |
| 响应式 | 支持PC端（1280px+），移动端适配为P2 |
| 错误提示 | 所有操作有明确的成功/失败反馈 |

### 5.3 数据安全

| 要求 | 说明 |
|------|------|
| API Key 加密存储 | 不明文存储，不在前端暴露 |
| 数据导出 | 支持用户导出全部个人数据 |
| 日志脱敏 | 采集日志不记录敏感内容 |

## 六、版本规划

### 6.1 MVP（v1.0）—— 核心闭环

**目标**：完成"上传/采集→分析→改写→导出"的完整链路

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 用户文档上传 | P0 | 批量上传文档，≥10篇自动分析，＜10篇提醒后继续；支持 TXT/MD/DOCX/PDF/HTML |
| 手动采集 | P1 | 关键词搜索，支持小红书+公众号+头条（采集源可用性依赖外部API） |
| 爆款分析 | P0 | 标题公式+情绪标签+评分（上传文档和采集结果均触发） |
| 跨平台改写 | P0 | 至少支持小红书+公众号+抖音 |
| 素材库基础 | P1 | 搜索+标签+收藏 |
| 首页看板 | P2 | 今日TOP5+趋势图（MVP阶段简化为最近采集+快捷入口） |

> **设计决策**：用户文档上传列为 P0，因为它是**不依赖任何外部 API 的确定性数据入口**，可保证核心链路在任何环境下可用。手动采集因依赖第三方 API 可用性，降为 P1。

### 6.2 v1.1 —— 自动化

- 定时采集计划
- 采集结果自动推送通知
- 素材库批量操作

### 6.3 v1.2 —— 数据驱动

- 数据中心（趋势图、平台对比、创作统计）
- 选题推荐引擎
- 周报/月报自动生成

### 6.4 v2.0 —— 协作化

- 团队空间
- 角色权限
- 选题审批流
- 发布日程

## 八、术语表

| 术语 | 定义 |
|------|------|
| 爆文 | 在某平台获得远超平均阅读/互动量的文章或笔记 |
| 爆款因子 | 衡量一篇文章"爆款潜力"的综合评分（0-100） |
| 标题公式 | 爆款标题的固定套路模式（如二极管法、数字法） |
| 情绪标签 | 文章传达的核心情绪类型 |
| 结构模板 | 文章内容的组织方式模板（如痛点→方案→总结） |
| 跨平台改写 | 将同一素材按不同平台的内容风格规则重写 |
| 采集计划 | 定时自动执行的热点采集任务配置 |
| 文档上传 | 用户将本地文档批量上传至系统，作为爆款分析的数据源 |
| 数量阈值 | 文档上传分析的最低推荐数量（10篇），低于此数量系统会提醒但不禁阻 |
