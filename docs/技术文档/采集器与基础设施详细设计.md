## 一、三层采集架构总览

```
┌─────────────────────────────────────────────────────────┐
│                    采集调度层                              │
│            CollectService（编排+降级+去重）                 │
└──────────┬──────────┬──────────┬────────────────────────┘
           │          │          │
     ┌─────▼────┐ ┌──▼─────┐ ┌─▼──────────┐
     │ 第一层    │ │ 第二层  │ │ 第三层          │
     │ API采集   │ │ 网页爬取 │ │ 用户上传+外部导入 │
     │ (最稳定)  │ │ (兜底)  │ │ (确定性入口)     │
     └─────┬────┘ └──┬─────┘ └─┬──────────┘
           │         │         │
     ┌─────▼────┐ ┌──▼─────┐ ┌─▼──────────┐
     │红狐数据API│ │Playwright│ │文档上传解析  │
     │开放平台API│ │httpx+BS4│ │POST /import│
     │          │ │RSS订阅   │ │Webhook回调 │
     └──────────┘ └────────┘ └────────────┘
```

**降级策略**：第一层失败 → 尝试第二层 → 仍失败 → 记录失败日志 + 返回部分结果 + 可通过第三层手动/自动补数据

## 二、采集器基类重设计

### 2.1 BaseCollector — 抽象基类（插件式）

```python
"""
采集器基类 v2。
核心改动：
1. 新增 source_type 字段（api/crawl/rss/import）
2. 新增 health_check() 健康检查
3. 新增 fallback 降级采集器注册
4. 新增 rate_limit_config 限流配置
5. normalize_article() 更严格，必填字段校验
"""
from abc import ABC, abstractmethod
from typing import Optional
from enum import Enum
from dataclasses import dataclass, field
from app.utils.http_client import HttpClient


class SourceType(str, Enum):
    API = "api"          # 调用官方/付费API
    CRAWL = "crawl"      # 网页爬取
    RSS = "rss"          # RSS/Atom订阅
    IMPORT = "import"    # 外部导入


class CollectStatus(str, Enum):
    SUCCESS = "success"
    PARTIAL = "partial"     # 部分成功
    FAILED = "failed"
    RATE_LIMITED = "rate_limited"   # 被限流
    AUTH_FAILED = "auth_failed"     # 认证失败
    TIMEOUT = "timeout"
    NO_RESULT = "no_result"         # 有响应但无结果


@dataclass
class CollectResult:
    """采集结果标准容器"""
    status: CollectStatus = CollectStatus.SUCCESS
    articles: list[dict] = field(default_factory=list)
    error_message: str = ""
    raw_count: int = 0          # 原始获取数量
    filtered_count: int = 0     # 去重后数量
    latency_ms: int = 0
    source_type: SourceType = SourceType.API
    platform: str = ""


class BaseCollector(ABC):
    """
    采集器抽象基类。
    所有采集器（API/爬虫/导入）都继承此类。
    """

    platform: str                       # 平台标识
    source_type: SourceType             # 数据来源类型
    display_name: str = ""              # 中文显示名
    requires_api_key: bool = False      # 是否需要API Key
    rate_limit_rpm: int = 60            # 每分钟请求上限
    timeout_seconds: int = 15           # 单次采集超时

    # 降级采集器（当主采集器失败时尝试）
    fallback_collector: Optional["BaseCollector"] = None

    def __init__(self, http_client: HttpClient = None):
        self.http_client = http_client or HttpClient()

    @abstractmethod
    async def collect(
        self,
        keyword: str,
        time_range: str = "7d",
        limit: int = 20,
        **kwargs
    ) -> CollectResult:
        """
        执行采集，返回 CollectResult。
        子类必须实现。
        """
        pass

    @abstractmethod
    async def health_check(self) -> dict:
        """
        健康检查。
        返回 {"available": bool, "message": str, "latency_ms": int}
        用于采集前预检和看板展示。
        """
        pass

    def validate_api_key(self, api_key: str = None) -> bool:
        """验证API Key是否有效（需要Key的采集器必须覆写）"""
        if self.requires_api_key:
            return bool(api_key and len(api_key) > 10)
        return True

    def set_fallback(self, collector: "BaseCollector"):
        """设置降级采集器"""
        self.fallback_collector = collector

    def normalize_article(self, raw: dict) -> dict:
        """
        将外部数据转为标准格式。
        严格校验必填字段，缺少必填字段的记录会被丢弃。
        """
        title = raw.get("title", "").strip()
        if not title:
            return None  # 无标题的记录直接丢弃

        return {
            # 必填
            "title": title,
            "platform": self.platform,
            # 可选但有默认值
            "content": raw.get("content", ""),
            "summary": raw.get("summary", ""),
            "url": raw.get("url", ""),
            "author": raw.get("author", ""),
            "published_at": raw.get("published_at"),
            "collected_at": raw.get("collected_at"),  # 由Service层补填
            "likes": int(raw.get("likes", 0) or 0),
            "collects": int(raw.get("collects", 0) or 0),
            "comments": int(raw.get("comments", 0) or 0),
            "shares": raw.get("shares"),
            "original_tags": raw.get("tags", []),
            # 采集元信息
            "source_type": self.source_type.value,
            "collector_name": self.__class__.__name__,
        }

    async def collect_with_fallback(
        self,
        keyword: str,
        time_range: str = "7d",
        limit: int = 20,
        **kwargs
    ) -> CollectResult:
        """
        带降级的采集。
        主采集器失败 → 尝试降级采集器 → 仍失败 → 返回失败结果
        """
        result = await self.collect(keyword, time_range, limit, **kwargs)

        if result.status in (CollectStatus.SUCCESS, CollectStatus.PARTIAL, CollectStatus.NO_RESULT):
            return result

        # 主采集器失败，尝试降级
        if self.fallback_collector:
            import logging
            logger = logging.getLogger(__name__)
            logger.warning(
                f"[{self.platform}] 主采集器 {self.__class__.__name__} 失败: {result.error_message}, "
                f"尝试降级到 {self.fallback_collector.__class__.__name__}"
            )
            fallback_result = await self.fallback_collector.collect(keyword, time_range, limit, **kwargs)
            fallback_result.status = CollectStatus.PARTIAL  # 降级结果标记为部分成功
            return fallback_result

        return result
```

## 三、第一层：API采集器（主力）

### 3.1 红狐数据采集器（小红书+公众号）

```python
"""
红狐数据采集器。
对接红狐数据API，采集小红书和公众号热门内容。
这是最稳定的数据源，优先使用。
"""
import time
import logging
from app.collectors.base_collector import (
    BaseCollector, SourceType, CollectResult, CollectStatus
)
from app.utils.http_client import HttpClient

logger = logging.getLogger(__name__)


class HonghuCollector(BaseCollector):
    """红狐数据采集器（小红书 + 公众号）"""

    BASE_URL = "https://api.honghudata.com/v1"
    source_type = SourceType.API
    requires_api_key = True
    rate_limit_rpm = 30  # 红狐数据限流较严

    def __init__(self, platform: str, http_client: HttpClient = None):
        super().__init__(http_client)
        assert platform in ("xiaohongshu", "wechat"), f"红狐不支持平台: {platform}"
        self.platform = platform
        self.display_name = "小红书" if platform == "xiaohongshu" else "公众号"

    async def collect(self, keyword: str, time_range: str = "7d", limit: int = 20, **kwargs) -> CollectResult:
        api_key = kwargs.get("api_key")
        if not self.validate_api_key(api_key):
            return CollectResult(
                status=CollectStatus.AUTH_FAILED,
                error_message=f"红狐数据API Key未配置或无效",
                platform=self.platform,
                source_type=self.source_type,
            )

        start = time.time()
        try:
            # 红狐数据请求参数
            params = {
                "keyword": keyword,
                "platform": "xhs" if self.platform == "xiaohongshu" else "wechat",
                "time_range": self._convert_time_range(time_range),
                "page_size": min(limit, 50),
                "sort": "hotness",
            }
            headers = {"Authorization": f"Bearer {api_key}"}

            resp = await self.http_client.get(
                f"{self.BASE_URL}/articles",
                params=params,
                headers=headers,
                timeout=self.timeout_seconds,
            )

            articles = []
            raw_items = resp.get("data", {}).get("items", [])

            for item in raw_items:
                normalized = self.normalize_article({
                    "title": item.get("title", ""),
                    "content": item.get("content", ""),
                    "summary": item.get("summary", ""),
                    "url": item.get("url", ""),
                    "author": item.get("author", ""),
                    "published_at": item.get("published_at"),
                    "likes": item.get("likes", 0),
                    "collects": item.get("collects", 0),
                    "comments": item.get("comments", 0),
                    "shares": item.get("shares"),
                    "tags": item.get("tags", []),
                })
                if normalized:
                    articles.append(normalized)

            latency = int((time.time() - start) * 1000)
            return CollectResult(
                status=CollectStatus.SUCCESS if articles else CollectStatus.NO_RESULT,
                articles=articles,
                raw_count=len(raw_items),
                filtered_count=len(articles),
                latency_ms=latency,
                source_type=self.source_type,
                platform=self.platform,
            )

        except TimeoutError:
            return CollectResult(
                status=CollectStatus.TIMEOUT,
                error_message=f"红狐数据请求超时（{self.timeout_seconds}s）",
                platform=self.platform,
                source_type=self.source_type,
            )
        except Exception as e:
            error_msg = str(e)
            # 识别限流
            if "429" in error_msg or "rate limit" in error_msg.lower():
                status = CollectStatus.RATE_LIMITED
            elif "401" in error_msg or "403" in error_msg:
                status = CollectStatus.AUTH_FAILED
            else:
                status = CollectStatus.FAILED

            return CollectResult(
                status=status,
                error_message=error_msg,
                platform=self.platform,
                source_type=self.source_type,
            )

    async def health_check(self) -> dict:
        """红狐数据健康检查：调用轻量级接口验证Key和连通性"""
        api_key = self._get_stored_api_key()
        if not api_key:
            return {"available": False, "message": "API Key未配置", "latency_ms": 0}

        start = time.time()
        try:
            resp = await self.http_client.get(
                f"{self.BASE_URL}/quota",
                headers={"Authorization": f"Bearer {api_key}"},
                timeout=5,
            )
            return {
                "available": True,
                "message": "正常",
                "latency_ms": int((time.time() - start) * 1000),
                "quota_remaining": resp.get("data", {}).get("remaining"),
            }
        except Exception as e:
            return {
                "available": False,
                "message": f"连接失败: {str(e)[:100]}",
                "latency_ms": int((time.time() - start) * 1000),
            }

    def _get_stored_api_key(self) -> str:
        """从数据库获取已存储的API Key（由Service层调用时传入）"""
        # 实际实现从 api_key 表读取并解密
        return ""

    @staticmethod
    def _convert_time_range(time_range: str) -> str:
        """将业务时间范围转为红狐API格式"""
        mapping = {"1d": "1", "3d": "3", "7d": "7", "30d": "30"}
        return mapping.get(time_range, "7")
```

### 3.2 搜索API采集器（头条/知乎/B站）

```python
"""
搜索API采集器。
通过通用搜索服务获取头条/知乎/B站内容。
不需要额外API Key（使用自建搜索或公共搜索API）。
"""
import time
import logging
from app.collectors.base_collector import (
    BaseCollector, SourceType, CollectResult, CollectStatus
)
from app.utils.http_client import HttpClient

logger = logging.getLogger(__name__)


class SearchCollector(BaseCollector):
    """联网搜索采集器（头条/知乎/B站）"""

    source_type = SourceType.API
    requires_api_key = False

    # 平台对应的搜索域名和内容特征
    PLATFORM_CONFIG = {
        "toutiao": {
            "domain": "toutiao.com",
            "display": "今日头条",
        },
        "zhihu": {
            "domain": "zhihu.com",
            "display": "知乎",
        },
        "bilibili": {
            "domain": "bilibili.com",
            "display": "哔哩哔哩",
        },
    }

    def __init__(self, platform: str, http_client: HttpClient = None):
        super().__init__(http_client)
        assert platform in self.PLATFORM_CONFIG, f"搜索采集器不支持平台: {platform}"
        self.platform = platform
        config = self.PLATFORM_CONFIG[platform]
        self.display_name = config["display"]
        self.site_domain = config["domain"]

    async def collect(self, keyword: str, time_range: str = "7d", limit: int = 20, **kwargs) -> CollectResult:
        start = time.time()

        try:
            # ===== 策略1：SerpAPI / Serper.dev 等搜索聚合API =====
            # 优先使用付费搜索API（结果质量高、稳定）
            search_api_key = kwargs.get("search_api_key")
            if search_api_key:
                return await self._collect_via_search_api(keyword, time_range, limit, search_api_key, start)

            # ===== 策略2：平台自有API（部分平台有公开接口）=====
            if self.platform == "bilibili":
                return await self._collect_bilibili_api(keyword, time_range, limit, start)
            elif self.platform == "zhihu":
                return await self._collect_zhihu_api(keyword, time_range, limit, start)
            elif self.platform == "toutiao":
                return await self._collect_toutiao_api(keyword, time_range, limit, start)

        except Exception as e:
            logger.error(f"[{self.platform}] 搜索采集失败: {e}")
            return CollectResult(
                status=CollectStatus.FAILED,
                error_message=str(e),
                platform=self.platform,
                source_type=self.source_type,
            )

    async def _collect_via_search_api(
        self, keyword: str, time_range: str, limit: int, api_key: str, start_time: float
    ) -> CollectResult:
        """通过搜索聚合API（如Serper.dev）采集"""
        search_query = f"{keyword} site:{self.site_domain}"
        params = {
            "q": search_query,
            "num": limit,
            "gl": "cn",
            "hl": "zh-cn",
        }
        headers = {"X-API-KEY": api_key}

        resp = await self.http_client.get(
            "https://google.serper.dev/search",
            params=params,
            headers=headers,
            timeout=self.timeout_seconds,
        )

        articles = []
        for item in resp.get("organic", []):
            normalized = self.normalize_article({
                "title": item.get("title", ""),
                "url": item.get("link", ""),
                "content": item.get("snippet", ""),
                "summary": item.get("snippet", ""),
                "published_at": item.get("date"),
            })
            if normalized:
                articles.append(normalized)

        latency = int((time.time() - start_time) * 1000)
        return CollectResult(
            status=CollectStatus.SUCCESS if articles else CollectStatus.NO_RESULT,
            articles=articles,
            raw_count=len(resp.get("organic", [])),
            filtered_count=len(articles),
            latency_ms=latency,
            source_type=self.source_type,
            platform=self.platform,
        )

    async def _collect_bilibili_api(
        self, keyword: str, time_range: str, limit: int, start_time: float
    ) -> CollectResult:
        """B站搜索API（公开接口，无需Key）"""
        params = {
            "keyword": keyword,
            "page_size": min(limit, 50),
            "order": "click",  # 按播放量排序
        }
        resp = await self.http_client.get(
            "https://api.bilibili.com/x/web-interface/search/type",
            params=params,
            timeout=self.timeout_seconds,
        )

        articles = []
        for item in resp.get("data", {}).get("result", []):
            normalized = self.normalize_article({
                "title": item.get("title", "").replace('<em class="keyword">', "").replace("</em>", ""),
                "url": f"https://www.bilibili.com/video/{item.get('bvid', '')}",
                "content": item.get("description", ""),
                "author": item.get("author", ""),
                "published_at": item.get("pubdate"),
                "likes": item.get("like", 0),
                "collects": item.get("favorites", 0),
                "comments": item.get("review", 0),
                "tags": item.get("tag", "").split(",") if item.get("tag") else [],
            })
            if normalized:
                articles.append(normalized)

        latency = int((time.time() - start_time) * 1000)
        return CollectResult(
            status=CollectStatus.SUCCESS if articles else CollectStatus.NO_RESULT,
            articles=articles,
            raw_count=len(resp.get("data", {}).get("result", [])),
            filtered_count=len(articles),
            latency_ms=latency,
            source_type=self.source_type,
            platform=self.platform,
        )

    async def _collect_zhihu_api(
        self, keyword: str, time_range: str, limit: int, start_time: float
    ) -> CollectResult:
        """知乎搜索API（公开接口，无需Key）"""
        params = {
            "q": keyword,
            "limit": min(limit, 50),
            "sort": "hot",  # 按热度排序
        }
        headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
        }

        resp = await self.http_client.get(
            "https://www.zhihu.com/api/v4/search_v3",
            params=params,
            headers=headers,
            timeout=self.timeout_seconds,
        )

        articles = []
        for item in resp.get("data", []):
            obj = item.get("object", {})
            normalized = self.normalize_article({
                "title": obj.get("title", ""),
                "url": obj.get("url", ""),
                "content": obj.get("excerpt", ""),
                "author": obj.get("author", {}).get("name", ""),
                "likes": obj.get("voteup_count", 0),
                "comments": obj.get("comment_count", 0),
            })
            if normalized:
                articles.append(normalized)

        latency = int((time.time() - start_time) * 1000)
        return CollectResult(
            status=CollectStatus.SUCCESS if articles else CollectStatus.NO_RESULT,
            articles=articles,
            filtered_count=len(articles),
            latency_ms=latency,
            source_type=self.source_type,
            platform=self.platform,
        )

    async def _collect_toutiao_api(
        self, keyword: str, time_range: str, limit: int, start_time: float
    ) -> CollectResult:
        """头条搜索API"""
        params = {
            "keyword": keyword,
            "count": min(limit, 50),
            "cur_tab": 1,
        }
        headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
        }

        resp = await self.http_client.get(
            "https://www.toutiao.com/api/search/content/",
            params=params,
            headers=headers,
            timeout=self.timeout_seconds,
        )

        articles = []
        for item in resp.get("data", []):
            normalized = self.normalize_article({
                "title": item.get("title", ""),
                "url": item.get("article_url", ""),
                "content": item.get("abstract", ""),
                "author": item.get("source", ""),
                "likes": item.get("digg_count", 0),
                "comments": item.get("comment_count", 0),
                "tags": item.get("label", []),
            })
            if normalized:
                articles.append(normalized)

        latency = int((time.time() - start_time) * 1000)
        return CollectResult(
            status=CollectStatus.SUCCESS if articles else CollectStatus.NO_RESULT,
            articles=articles,
            filtered_count=len(articles),
            latency_ms=latency,
            source_type=self.source_type,
            platform=self.platform,
        )

    async def health_check(self) -> dict:
        start = time.time()
        try:
            # 简单发一个搜索请求验证连通性
            resp = await self.http_client.get(
                f"https://www.{self.site_domain}",
                timeout=5,
            )
            return {
                "available": True,
                "message": "正常",
                "latency_ms": int((time.time() - start) * 1000),
            }
        except Exception as e:
            return {
                "available": False,
                "message": f"连接失败: {str(e)[:100]}",
                "latency_ms": int((time.time() - start) * 1000),
            }
```

## 四、第二层：网页爬取采集器（兜底）

### 4.1 爬取采集器基类

```python
"""
网页爬取采集器基类。
使用 Playwright（动态渲染） + httpx+BeautifulSoup（静态页面）双模式。
"""
import time
import logging
from abc import abstractmethod
from app.collectors.base_collector import (
    BaseCollector, SourceType, CollectResult, CollectStatus
)
from app.utils.http_client import HttpClient

logger = logging.getLogger(__name__)


class CrawlCollector(BaseCollector):
    """网页爬取采集器基类"""

    source_type = SourceType.CRAWL
    requires_api_key = False

    # 爬取配置
    use_playwright: bool = False  # 是否需要动态渲染（JS重页面）
    max_concurrent: int = 3       # 最大并发页数
    delay_range: tuple = (1, 3)   # 请求间隔（秒），模拟人类

    def __init__(self, platform: str, http_client: HttpClient = None):
        super().__init__(http_client)
        self.platform = platform

    @abstractmethod
    def get_search_url(self, keyword: str, page: int = 1) -> str:
        """根据关键词生成搜索页URL"""
        pass

    @abstractmethod
    def parse_list_page(self, html: str) -> list[dict]:
        """解析搜索结果列表页，返回 [{title, url, ...}] 摘要信息"""
        pass

    @abstractmethod
    def parse_detail_page(self, html: str, url: str) -> dict:
        """解析文章详情页，返回完整文章信息"""
        pass

    async def collect(self, keyword: str, time_range: str = "7d", limit: int = 20, **kwargs) -> CollectResult:
        start = time.time()

        try:
            # 第一步：获取搜索结果列表
            search_url = self.get_search_url(keyword)
            html = await self._fetch_page(search_url)
            if not html:
                return CollectResult(
                    status=CollectStatus.FAILED,
                    error_message="搜索页获取失败",
                    platform=self.platform,
                    source_type=self.source_type,
                )

            list_items = self.parse_list_page(html)
            if not list_items:
                return CollectResult(
                    status=CollectStatus.NO_RESULT,
                    platform=self.platform,
                    source_type=self.source_type,
                )

            # 第二步：选择性获取详情页（前N条）
            articles = []
            for item in list_items[:limit]:
                import asyncio
                import random
                await asyncio.sleep(random.uniform(*self.delay_range))  # 模拟人类间隔

                detail_url = item.get("url")
                if detail_url:
                    detail_html = await self._fetch_page(detail_url)
                    if detail_html:
                        parsed = self.parse_detail_page(detail_html, detail_url)
                        parsed.update(item)  # 合并列表页信息
                    else:
                        parsed = item  # 详情页获取失败，用列表页摘要
                else:
                    parsed = item

                normalized = self.normalize_article(parsed)
                if normalized:
                    articles.append(normalized)

            latency = int((time.time() - start) * 1000)
            return CollectResult(
                status=CollectStatus.SUCCESS if articles else CollectStatus.NO_RESULT,
                articles=articles,
                raw_count=len(list_items),
                filtered_count=len(articles),
                latency_ms=latency,
                source_type=self.source_type,
                platform=self.platform,
            )

        except Exception as e:
            logger.error(f"[{self.platform}] 爬取采集失败: {e}")
            return CollectResult(
                status=CollectStatus.FAILED,
                error_message=str(e),
                platform=self.platform,
                source_type=self.source_type,
            )

    async def _fetch_page(self, url: str) -> str | None:
        """获取网页内容（静态 or 动态渲染）"""
        if self.use_playwright:
            return await self._fetch_with_playwright(url)
        else:
            return await self._fetch_with_httpx(url)

    async def _fetch_with_httpx(self, url: str) -> str | None:
        """静态页面获取（httpx + 伪装UA）"""
        headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                          "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
            "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
            "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
        }
        try:
            resp = await self.http_client.get(url, headers=headers, timeout=self.timeout_seconds)
            return resp if isinstance(resp, str) else str(resp)
        except Exception as e:
            logger.warning(f"静态获取失败 [{url}]: {e}")
            return None

    async def _fetch_with_playwright(self, url: str) -> str | None:
        """
        动态渲染获取（Playwright）。
        需要单独安装 playwright + 浏览器。
        用于小红书、抖音等重JS页面。
        """
        try:
            from playwright.async_api import async_playwright
            async with async_playwright() as p:
                browser = await p.chromium.launch(headless=True)
                page = await browser.new_page()
                # 伪装
                await page.set_extra_http_headers({
                    "Accept-Language": "zh-CN,zh;q=0.9",
                })
                await page.goto(url, wait_until="networkidle", timeout=self.timeout_seconds * 1000)
                html = await page.content()
                await browser.close()
                return html
        except ImportError:
            logger.warning("Playwright未安装，跳过动态渲染")
            return None
        except Exception as e:
            logger.warning(f"Playwright获取失败 [{url}]: {e}")
            return None

    async def health_check(self) -> dict:
        start = time.time()
        try:
            html = await self._fetch_page(self.get_search_url("test"))
            return {
                "available": bool(html),
                "message": "正常" if html else "页面获取失败",
                "latency_ms": int((time.time() - start) * 1000),
            }
        except Exception as e:
            return {
                "available": False,
                "message": str(e)[:100],
                "latency_ms": int((time.time() - start) * 1000),
            }
```

## 五、第三层：用户上传 + 外部数据导入

> **核心设计**：
> - **用户文档上传**（P0）：用户直接上传本地文档（TXT/MD/DOCX/PDF/HTML），系统自动解析为结构化素材。这是不依赖任何外部 API 的确定性数据入口，MVP 核心链路。
> - **外部数据导入**（P1）：当自有采集器全部失败时，任何外部爬虫/脚本只要按照标准格式推送数据，就能无缝对接到爆文猎人的数据库。
>
> 两者的数据最终都汇入 `article` 表，通过 `collection_method` 字段区分来源（`upload` / `api` / `import`）。

### 5.0 用户文档上传 — 解析器架构

```
用户上传文件
  → UploadService 接收 multipart/form-data
  → 按 file_format 分发到对应 Parser：
     ├─ txtparser    → .txt / .md
     ├─ docxparser   → .docx (python-docx)
     ├─ pdfparser    → .pdf (pdfplumber + PyPDF2 fallback)
     └─ htmlparser   → .html (BeautifulSoup)
  → Parser 输出 ParseResult {title, content, word_count, ...}
  → 内容校验（≥50字 / 去重 / 编码检测）
  → 写入 article 表 + upload_file 表
  → 判断 effective_count ≥ 10 → 自动触发爆款分析
```

#### 5.0.1 解析器基类

```python
"""
文档解析器基类。
所有格式解析器继承此类，统一接口和异常处理。
"""
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from enum import Enum


class ParseStatus(str, Enum):
    SUCCESS = "success"
    FAILED = "failed"
    EMPTY_CONTENT = "empty_content"       # 内容为空或过短
    ENCODING_ERROR = "encoding_error"     # 编码无法识别
    SCAN_ONLY_PDF = "scan_only_pdf"       # PDF为扫描件


@dataclass
class ParseResult:
    """解析结果"""
    status: ParseStatus = ParseStatus.SUCCESS
    title: str = ""
    content: str = ""
    word_count: int = 0
    error_message: str = ""
    metadata: dict = field(default_factory=dict)

    MIN_CONTENT_LENGTH = 50  # 有效内容最低字数

    def is_valid(self) -> bool:
        """内容是否有效（成功且字数达标）"""
        return (
            self.status == ParseStatus.SUCCESS
            and len(self.content.strip()) >= self.MIN_CONTENT_LENGTH
        )


class BaseParser(ABC):
    """文档解析器抽象基类"""

    supported_extensions: list[str] = []

    @abstractmethod
    async def parse(self, file_content: bytes, filename: str) -> ParseResult:
        """
        解析文件内容。
        Args:
            file_content: 文件原始字节
            filename: 文件名（用于推断格式和提取默认标题）
        Returns:
            ParseResult
        """
        pass

    def extract_title_from_filename(self, filename: str) -> str:
        """从文件名提取标题（去除扩展名）"""
        import os
        return os.path.splitext(filename)[0].strip()
```

#### 5.0.2 文档解析器实现（示例：TXT/MD）

```python
"""
TXT 和 Markdown 文件解析器。
"""
import chardet
from app.parsers.base_parser import BaseParser, ParseResult, ParseStatus


class TxtParser(BaseParser):
    supported_extensions = [".txt", ".md"]

    async def parse(self, file_content: bytes, filename: str) -> ParseResult:
        # 1. 编码检测
        try:
            detected = chardet.detect(file_content)
            encoding = detected.get("encoding", "utf-8") or "utf-8"
            text = file_content.decode(encoding, errors="replace")
        except Exception as e:
            return ParseResult(
                status=ParseStatus.ENCODING_ERROR,
                error_message=f"编码检测失败: {e}",
            )

        # 2. Markdown 去除标记语法（保留标题层级作为结构参考）
        if filename.endswith(".md"):
            import re
            title_match = re.search(r"^#+\s+(.+)", text, re.MULTILINE)
            title = title_match.group(1).strip() if title_match else ""
            content = re.sub(r"[#*_~`>\[\]()!]", "", text).strip()
        else:
            title = ""
            content = text.strip()

        # 3. 如果没有从内容提取到标题，用文件名
        if not title:
            title = self.extract_title_from_filename(filename)

        return ParseResult(
            status=ParseStatus.SUCCESS,
            title=title,
            content=content,
            word_count=len(content),
            metadata={"encoding": encoding, "format": "txt"},
        )
```

> 其余解析器（DocxParser、PdfParser、HtmlParser）按相同模式实现，详见 `backend/app/parsers/` 目录。

```python
# UploadService 中的阈值判断逻辑
UPLOAD_THRESHOLD = 10  # 推荐最低文档数

async def _check_threshold_and_trigger_analysis(
    self, batch_id: str, effective_count: int
):
    """判断是否达到分析阈值，决定是否自动触发分析"""
    if effective_count == 0:
        return {"action": "none", "message": "没有有效的文档可供分析"}

    if effective_count >= UPLOAD_THRESHOLD:
        # 达标，自动触发
        task_id = await self._trigger_analysis(batch_id)
        return {"action": "auto_analyze", "task_id": task_id}
    else:
        # 未达标，等待用户确认
        return {
            "action": "confirm_required",
            "message": f"当前有效文档仅 {effective_count} 篇，"
                       f"推荐至少上传 {UPLOAD_THRESHOLD} 篇以获得更准确的分析结果",
```

## 六、采集器注册与编排

### 6.1 CollectorRegistry — 采集器注册中心

```python
"""
采集器注册中心。
统一管理所有采集器实例，支持：
1. 按平台获取可用采集器
2. 自动组装降级链
3. 健康检查总览
"""
import logging
from typing import Optional
from app.collectors.base_collector import BaseCollector, CollectResult, CollectStatus

logger = logging.getLogger(__name__)


class CollectorRegistry:
    """采集器注册中心"""

    _registry: dict[str, list[BaseCollector]] = {}  # {platform: [collector1, collector2, ...]}

    @classmethod
    def register(cls, collector: BaseCollector, platform: str = None):
        """注册采集器，按优先级排列（第一个最优先）"""
        key = platform or collector.platform
        if key not in cls._registry:
            cls._registry[key] = []
        cls._registry[key].append(collector)
        logger.info(f"注册采集器: {collector.__class__.__name__} → {key} (优先级: {len(cls._registry[key])})")

    @classmethod
    def get_collectors(cls, platform: str) -> list[BaseCollector]:
        """获取指定平台的所有采集器（按优先级排序）"""
        return cls._registry.get(platform, [])

    @classmethod
    def get_primary(cls, platform: str) -> Optional[BaseCollector]:
        """获取指定平台的主采集器（最优先）"""
        collectors = cls.get_collectors(platform)
        return collectors[0] if collectors else None

    @classmethod
    async def collect_with_fallback_chain(
        cls,
        platform: str,
        keyword: str,
        time_range: str = "7d",
        limit: int = 20,
        **kwargs
    ) -> CollectResult:
        """
        按降级链依次尝试采集。
        主采集器失败 → 第二优先 → 第三优先 → ... → 全部失败
        """
        collectors = cls.get_collectors(platform)
        if not collectors:
            return CollectResult(
                status=CollectStatus.FAILED,
                error_message=f"平台 {platform} 无可用采集器",
                platform=platform,
            )

        last_error = ""
        for i, collector in enumerate(collectors):
            logger.info(f"[{platform}] 尝试采集器 #{i+1}: {collector.__class__.__name__}")
            result = await collector.collect(keyword, time_range, limit, **kwargs)

            if result.status in (CollectStatus.SUCCESS, CollectStatus.PARTIAL, CollectStatus.NO_RESULT):
                if i > 0:
                    result.status = CollectStatus.PARTIAL  # 降级成功标记为部分成功
                    result.error_message = f"主采集器失败，降级到 {collector.__class__.__name__}"
                return result

            last_error = result.error_message
            logger.warning(
                f"[{platform}] 采集器 {collector.__class__.__name__} 失败: {last_error}"
            )

        return CollectResult(
            status=CollectStatus.FAILED,
            error_message=f"所有采集器均失败，最后错误: {last_error}",
            platform=platform,
        )

    @classmethod
    async def health_check_all(cls) -> dict[str, dict]:
        """对所有平台的所有采集器做健康检查"""
        results = {}
        for platform, collectors in cls._registry.items():
            results[platform] = {
                collector.__class__.__name__: await collector.health_check()
                for collector in collectors
            }
        return results

    @classmethod
    def list_all(cls) -> dict[str, list[str]]:
        """列出所有已注册的采集器"""
        return {
            platform: [c.__class__.__name__ for c in collectors]
            for platform, collectors in cls._registry.items()
        }
```

## 七、采集编排服务（CollectService 核心逻辑）

```python
"""
采集编排服务。
负责：多平台并行采集、降级、去重、入库。
"""
import asyncio
import time
import logging
from datetime import datetime
from typing import Optional
from sqlalchemy.ext.asyncio import AsyncSession

from app.collectors.registry import CollectorRegistry
from app.collectors.base_collector import CollectResult, CollectStatus
from app.models.article import Article
from app.models.collect_log import CollectLog
from app.utils.hotness_scorer import HotnessScorer
from app.utils.emotion_tagger import EmotionTagger
from app.base.enum_base import Platform

logger = logging.getLogger(__name__)


class CollectService:
    """采集编排服务"""

    def __init__(self, session: AsyncSession):
        self.session = session

    async def manual_collect(
        self,
        keyword: str,
        platforms: list[str],
        time_range: str = "7d",
        limit: int = 20,
        api_keys: dict[str, str] = None,
    ) -> dict:
        """
        手动采集入口。
        多平台并行采集，各平台独立降级。
        """
        api_keys = api_keys or {}
        start_time = time.time()

        # 创建采集日志
        log = CollectLog(
            type="manual",
            keywords=[keyword],
            platforms=platforms,
            status="running",
            started_at=datetime.now(),
        )
        self.session.add(log)
        await self.session.flush()

        # ===== 多平台并行采集 =====
        tasks = []
        for platform in platforms:
            task = CollectorRegistry.collect_with_fallback_chain(
                platform=platform,
                keyword=keyword,
                time_range=time_range,
                limit=limit,
                api_key=api_keys.get(platform),
            )
            tasks.append((platform, task))

        # 并行执行，各平台互不影响
        results: dict[str, CollectResult] = {}
        for platform, task in tasks:
            try:
                results[platform] = await asyncio.wait_for(task, timeout=30)
            except asyncio.TimeoutError:
                results[platform] = CollectResult(
                    status=CollectStatus.TIMEOUT,
                    error_message="采集超时（30s）",
                    platform=platform,
                )

        # ===== 汇总结果 =====
        all_articles = []
        success_platforms = []
        failed_platforms = []

        for platform, result in results.items():
            if result.status in (CollectStatus.SUCCESS, CollectStatus.PARTIAL):
                success_platforms.append(platform)
                all_articles.extend(result.articles)
            elif result.status == CollectStatus.NO_RESULT:
                success_platforms.append(platform)  # 成功但无结果
            else:
                failed_platforms.append({"platform": platform, "reason": result.error_message})

        # ===== 去重 =====
        seen = set()
        unique_articles = []
        for article in all_articles:
            key = (article["title"], article["platform"])
            if key not in seen:
                seen.add(key)
                unique_articles.append(article)

        # ===== 入库 + 自动分析 =====
        imported_ids = []
        for article_data in unique_articles:
            # 计算热度评分
            if article_data.get("hotness_score") is None:
                article_data["hotness_score"] = HotnessScorer.quick_score(article_data)

            # 情绪标注
            if not article_data.get("emotion_tags"):
                article_data["emotion_tags"] = EmotionTagger.tag(
                    article_data.get("title", "") + " " + article_data.get("content", "")
                )

            # 写入数据库
            article = Article(**article_data, collect_log_id=log.id)
            self.session.add(article)
            imported_ids.append(article.id)

        # 更新日志
        total_duration = int((time.time() - start_time) * 1000)
        log.result_count = len(unique_articles)
        log.status = "success" if not failed_platforms else "partial"
        log.finished_at = datetime.now()
        log.duration_ms = total_duration
        if failed_platforms:
            log.error_message = "; ".join(
                f"{f['platform']}: {f['reason']}" for f in failed_platforms
            )

        await self.session.flush()

        return {
            "log_id": log.id,
            "status": log.status,
            "total": len(unique_articles),
            "success_platforms": success_platforms,
            "failed_platforms": failed_platforms,
            "duration_ms": total_duration,
            "imported_ids": imported_ids,
        }
```

## 八、各平台采集方案总结

| 平台 | 第一层（API） | 第二层（爬取） | 第三层（导入） | 难度 | 推荐 |
|------|-------------|--------------|-------------|------|------|
| 小红书 | 红狐数据API ✅ | Playwright动态渲染 ⚠️ | /import/articles | ⭐⭐ | 红狐API优先 |
| 公众号 | 红狐数据API ✅ | 搜狗微信搜索 ⚠️ | /import/articles | ⭐⭐ | 红狐API优先 |
| 今日头条 | 平台API ⚠️ | — | /import/articles | ⭐⭐ | SearchCollector |
| 知乎 | 平台API ⚠️ | BeautifulSoup爬取 ⚠️ | /import/articles | ⭐⭐ | SearchCollector优先 |
| B站 | B站搜索API ✅ | — | /import/articles | ⭐ | B站API优先 |
| 抖音 | ❌ 无公开API | ❌ 反爬极严 | ✅ /import/articles | ⭐⭐⭐⭐⭐ | **必须外部导入** |
| 快手 | ❌ 无公开API | ❌ 反爬极严 | ✅ /import/articles | ⭐⭐⭐⭐⭐ | **必须外部导入** |
| 视频号 | ❌ 无公开API | ❌ 反爬极严 | ✅ /import/articles | ⭐⭐⭐⭐⭐ | **必须外部导入** |

**难度说明**：⭐最简单（有稳定API） → ⭐⭐⭐⭐⭐最难（必须模拟App操作）

**关键结论**：
- 小红书/公众号/B站：自有采集器能搞定
- 头条/知乎：自有采集器大部分时候能用，偶尔需要兜底
- **抖音/快手/视频号：必须靠外部爬虫 + `/import/articles` 接口**

## 九、反爬策略与应对

| 反爬手段 | 应对方案 | 实现位置 |
|----------|---------|---------|
| User-Agent检测 | 随机UA池，每次请求切换 | `CrawlCollector._fetch_with_httpx` |
| IP限流 | 代理IP池（P2扩展）/ 降低采集频率 | `CrawlCollector.delay_range` |
| Cookie/登录验证 | Playwright自动处理Cookie | `CrawlCollector._fetch_with_playwright` |
| JS动态渲染 | Playwright headless浏览器渲染 | `CrawlCollector.use_playwright=True` |
| 验证码 | 暂不处理，失败后降级到外部导入 | 采集降级链 |
| 数据加密 | 前端JS加密的，需Playwright渲染后提取 | 爬取采集器 |
| 接口签名 | 逆向分析签名算法（P2扩展） | 采集器子类 |

**原则**：反爬对抗是无底洞，我们的策略是 **API优先 + 适度爬取 + 外部导入兜底**，不做暴力爬取。

## 十三、总结：采集架构核心设计原则

```
┌─────────────────────────────────────────────────┐
│              核心原则：三层兜底                    │
├─────────────────────────────────────────────────┤
│                                                  │
│  1. API优先 → 最稳定、最合规、质量最高            │
│  2. 爬取兜底 → API失败时的备选方案               │
│  3. 外部导入 → 爬取也搞不定的平台（抖音/快手）    │
│     预留标准接口，任何外部爬虫都能对接            │
│                                                  │
│  关键设计：                                       │
│  • CollectorRegistry 降级链自动切换               │
│  • ExternalOnlyCollector 标记仅导入平台            │
│  • POST /import/articles 标准化数据入口           │
│  • GET /import/template 对接参考模板              │
│  • Webhook回调 实时推送采集结果                   │
│                                                  │
│  失败不慌：                                       │
│  • 部分成功也入库，不浪费已采集数据               │
│  • 失败平台记录原因，可重试                       │
│  • 抖音/快手/视频号 → 引导用户用导入接口          │
│                                                  │
└─────────────────────────────────────────────────┘
```
