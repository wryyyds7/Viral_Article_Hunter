## 一、架构决策

### 1.1 产品形态

| 决策 | 结论 |
|------|------|
| 产品形态 | 多人 SaaS，部署在公网 |
| 登录方式 | MVP：邮箱+密码。v2.0预留手机号验证码 |
| 数据隔离 | 采集结果共享，上传/分析/改写私有 |
| 角色体系 | MVP：单角色（普通用户）。v2.0：管理员+普通用户 |

### 1.2 数据隔离策略（混合模式）

| 数据类型 | 隔离级别 | 说明 |
|----------|----------|------|
| 热点采集结果 | **共享** | 所有用户可查看，采集一次全员受益，节省API费用 |
| 用户上传文档 | **私有** | 仅上传者可见 |
| 爆款分析结果 | **私有** | 分析基于用户视角，仅分析者可见 |
| 改写结果 | **私有** | 改写是用户创作成果，仅本人可见 |
| 个人设置 | **私有** | API Key、偏好等仅本人可见 |
| 素材库收藏 | **私有** | 用户个人的收藏/分组 |

**实现方式**：

```
共享数据（采集结果）：
  article.collection_method = 'api' OR 'crawl'
  → article.user_id = NULL（系统数据，无归属）
  → 所有用户可通过 /v1/collect/results 查看

私有数据（上传/分析/改写）：
  article.collection_method = 'upload'
  → article.user_id = 当前用户ID
  → 只能本人查看
```

## 二、用户数据模型

### 2.1 users 表

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,     -- bcrypt哈希
    nickname VARCHAR(100),                    -- 显示名称
    avatar_url VARCHAR(500),                  -- 头像URL
    role VARCHAR(20) NOT NULL DEFAULT 'user', -- user / admin（v2.0）
    status VARCHAR(20) NOT NULL DEFAULT 'active', -- active / disabled
    
    -- 用量统计（冗余字段，定时更新）
    total_analyses INT DEFAULT 0,             -- 累计分析次数
    total_rewrites INT DEFAULT 0,             -- 累计改写次数
    total_uploads INT DEFAULT 0,              -- 累计上传文件数
    
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    last_login_at TIMESTAMP,
    
    CONSTRAINT ck_role CHECK (role IN ('user', 'admin')),
    CONSTRAINT ck_status CHECK (status IN ('active', 'disabled'))
);

CREATE INDEX idx_users_email ON users(email);
```

### 2.2 refresh_tokens 表（刷新令牌）

```sql
CREATE TABLE refresh_tokens (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    token_hash VARCHAR(255) NOT NULL,         -- 令牌哈希
    device_info VARCHAR(500),                 -- 设备信息
    ip_address VARCHAR(45),                   -- 登录IP
    expires_at TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT NOW(),
    revoked_at TIMESTAMP                      -- 撤销时间
);

CREATE INDEX idx_refresh_tokens_user ON refresh_tokens(user_id, revoked_at);
```

### 2.3 user_quotas 表（用户配额）

```sql
CREATE TABLE user_quotas (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL UNIQUE REFERENCES users(id) ON DELETE CASCADE,
    
    -- 每日限额
    daily_analyses_limit INT NOT NULL DEFAULT 50,       -- 每日分析次数
    daily_rewrites_limit INT NOT NULL DEFAULT 20,       -- 每日改写次数
    daily_uploads_limit INT NOT NULL DEFAULT 50,        -- 每日上传文件数
    daily_uploads_size_limit_mb INT NOT NULL DEFAULT 50, -- 每日上传总大小(MB)
    
    -- 当日已用（每日0点重置）
    daily_analyses_used INT DEFAULT 0,
    daily_rewrites_used INT DEFAULT 0,
    daily_uploads_used INT DEFAULT 0,
    daily_uploads_size_used_mb DECIMAL(10,2) DEFAULT 0,
    
    -- 重置时间
    last_reset_at DATE NOT NULL DEFAULT CURRENT_DATE,
    
    updated_at TIMESTAMP DEFAULT NOW()
);
```

## 三、认证方案

### 3.1 Token 方案：双Token机制

| Token | 用途 | 有效期 | 存储 |
|-------|------|--------|------|
| Access Token | API请求鉴权 | 2小时 | 前端内存（不存localStorage） |
| Refresh Token | 刷新Access Token | 30天 | HttpOnly Cookie |

**选择理由**：
- Access Token 短效，即使泄露影响有限
- Refresh Token 长效但存 HttpOnly Cookie，XSS无法窃取
- 不使用 JWT 无状态方案（需要支持主动注销和禁用用户）

### 3.2 认证流程

```
┌──────────────────────────────────────────────────┐
│                  注册流程                          │
│                                                  │
│  POST /v1/auth/register                         │
│  { email, password, nickname? }                  │
│       │                                          │
│       ▼                                          │
│  校验邮箱格式 + 密码强度(≥8位,含字母+数字)        │
│       │                                          │
│       ▼                                          │
│  检查邮箱是否已注册                               │
│       │                                          │
│       ▼                                          │
│  bcrypt哈希密码(cost=12) → 写入users表           │
│       │                                          │
│       ▼                                          │
│  初始化 user_quotas 默认配额                      │
│       │                                          │
│       ▼                                          │
│  返回 Access Token + Refresh Token               │
│  （注册即登录，无需二次登录）                      │
└──────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────┐
│                  登录流程                          │
│                                                  │
│  POST /v1/auth/login                            │
│  { email, password }                            │
│       │                                          │
│       ▼                                          │
│  查询用户 → bcrypt验证密码                       │
│       │                                          │
│       ├─ 失败：返回401，记录失败次数               │
│       │   连续5次失败 → 锁定15分钟                │
│       ▼                                          │
│  生成 Access Token + Refresh Token               │
│       │                                          │
│       ▼                                          │
│  更新 last_login_at                              │
│       │                                          │
│       ▼                                          │
│  返回 Token + 用户信息                            │
└──────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────┐
│                  Token刷新流程                     │
│                                                  │
│  POST /v1/auth/refresh                          │
│  Cookie: refresh_token=xxx                       │
│       │                                          │
│       ▼                                          │
│  验证Refresh Token有效性(未过期+未撤销)           │
│       │                                          │
│       ▼                                          │
│  生成新Access Token + 新Refresh Token            │
│       │                                          │
│       ▼                                          │
│  旧Refresh Token标记为已撤销                     │
└──────────────────────────────────────────────────┘
```

### 3.3 密码安全策略

| 策略 | 规则 |
|------|------|
| 最小长度 | 8位 |
| 复杂度 | 必须包含字母+数字 |
| 哈希算法 | bcrypt，cost=12 |
| 登录失败锁定 | 连续5次失败，锁定15分钟 |
| 密码修改 | 需验证旧密码（v2.0实现） |
| 密码重置 | 通过邮箱验证码（v2.0实现） |

### 3.4 密码哈希实现

```python
from passlib.context import CryptContext

pwd_context = CryptContext(
    schemes=["bcrypt"],
    deprecated="auto",
    bcrypt__rounds=12
)

# 哈希
hashed = pwd_context.hash(plain_password)

# 验证
is_valid = pwd_context.verify(plain_password, hashed)
```

## 四、鉴权中间件

### 4.1 FastAPI依赖注入

```python
from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials

security = HTTPBearer()

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security),
    db: AsyncSession = Depends(get_db)
) -> User:
    """从Access Token解析当前用户"""
    token = credentials.credentials
    try:
        payload = decode_access_token(token)
        user_id = payload.get("sub")
        if user_id is None:
            raise HTTPException(status_code=401, detail="无效的认证令牌")
    except TokenExpiredError:
        raise HTTPException(status_code=40101, detail="认证令牌已过期")
    except InvalidTokenError:
        raise HTTPException(status_code=40102, detail="无效的认证令牌")
    
    user = await db.get(User, user_id)
    if user is None or user.status == "disabled":
        raise HTTPException(status_code=40103, detail="用户不存在或已被禁用")
    
    return user

async def get_current_user_optional(
    credentials: HTTPAuthorizationCredentials = Depends(security)
) -> Optional[User]:
    """可选认证——共享数据接口，未登录也可访问部分数据"""
    # 实现同上，但token无效时返回None而非抛异常
    pass
```

### 5.1 查询层隔离

```python
# 共享数据查询（采集结果）
async def get_shared_articles(db: AsyncSession, filters: dict):
    """获取共享采集结果——所有用户可见"""
    query = select(Article).where(
        Article.collection_method.in_(['api', 'crawl']),
        Article.is_deleted == False
    )
    # 应用筛选条件...
    return await db.execute(query)

# 私有数据查询（用户自己的数据）
async def get_user_articles(db: AsyncSession, user_id: UUID, filters: dict):
    """获取用户私有数据——上传+收藏"""
    query = select(Article).where(
        Article.user_id == user_id,
        Article.is_deleted == False
    )
    # 应用筛选条件...
    return await db.execute(query)

# 混合查询（我的素材库 = 共享收藏 + 私有上传）
async def get_library_articles(db: AsyncSession, user_id: UUID, filters: dict):
    """素材库：共享采集中被收藏的 + 用户上传的"""
    query = select(Article).where(
        or_(
            and_(Article.user_id == user_id),  # 私有
            and_(Article.collection_method.in_(['api', 'crawl']),
                 Article.is_favorited == True,
                 Article.favorited_by == user_id)  # 共享但被收藏
        ),
        Article.is_deleted == False
    )
    return await db.execute(query)
```

## 六、配额与限流

### 6.1 用户配额检查

```python
async def check_quota(db: AsyncSession, user_id: UUID, action: str) -> bool:
    """检查用户配额，超限返回False"""
    quota = await db.get(UserQuota, user_id)
    
    # 检查是否需要重置（跨日）
    if quota.last_reset_at < date.today():
        await reset_daily_quota(db, quota)
    
    mapping = {
        "analysis": ("daily_analyses_used", "daily_analyses_limit"),
        "rewrite": ("daily_rewrites_used", "daily_rewrites_limit"),
        "upload": ("daily_uploads_used", "daily_uploads_limit"),
    }
    
    used_field, limit_field = mapping[action]
    if getattr(quota, used_field) >= getattr(quota, limit_field):
        return False  # 超限
    return True

async def consume_quota(db: AsyncSession, user_id: UUID, action: str, amount: int = 1):
    """消耗配额"""
    quota = await db.get(UserQuota, user_id)
    used_field = {
        "analysis": "daily_analyses_used",
        "rewrite": "daily_rewrites_used",
        "upload": "daily_uploads_used",
    }[action]
    setattr(quota, used_field, getattr(quota, used_field) + amount)
    await db.commit()
```

CREATE TABLE organizations (
