## 一、backend/ — Python FastAPI 后端

```
backend/
│

│   │
│   ├── __init__.py
│   ├── main.py                       # FastAPI 应用入口

│   │                                 # - lifespan: 启动时创建表 + 注册 EventBus + 启动 Worker + 启动 Scheduler
│   │                                 # - lifespan: 关闭时停止 Scheduler + 停止 Worker + 关闭 DB 连接池

│   ├── config.py                     # 全局配置（pydantic-settings）

## 二、server/ — Express 代理层

```
server/
│
├── server.ts                         # Express 入口
│                                     # - 反向代理: /api/* → Python /v1/*
│                                     # - 支持 JSON 和 multipart/form-data 透传
│                                     # - Vite Dev Middleware 集成
│                                     # - 生产模式静态文件服务
│
├── vite.ts                           # Vite 开发中间件配置
│
├── routes/                           # (已废弃，保留参考)
│   ├── index.ts                      # 原代理逻辑(已被 server.ts 内联)
│   ├── auth.ts                       # 原 Supabase 路由(已废弃)
│   ├── collection.ts                 # 原 Mock 数据路由(已废弃)
│   └── ...                           # 其他原路由(已废弃)
│
└── src/
    └── storage/
        └── database/
            ├── supabase-client.ts    # Supabase 客户端(已废弃)
            └── shared/
                ├── schema.ts         # Drizzle Schema(仅参考)
                ├── types.ts          # 类型定义
                └── relations.ts      # 关系定义
```

> **注意**: `server/routes/` 下的文件已废弃，Express 现在是纯代理层，所有 API 请求转发到 Python 后端。

## 三、src/ — 前端源码（TypeScript SPA）

```
src/
│
├── main.ts                           # 主应用逻辑
│                                     # - 页面渲染: Login/Dashboard/Collect/Articles/
│                                     #   Upload/Rewrite/AnalysisDetail/Settings/Admin

│                                     # - JWT Token 管理(setAuthToken/getAuthToken)
│                                     # - apiFetch: 自动注入 Authorization header
│                                     # - 10 个 API 模块: auth/collection/analysis/rewrite/
│                                     #   article/upload/analytics/settings/admin
│                                     # - 类型定义: 20+ interface
│
├── router.ts                         # SPA 路由
│                                     # - 支持静态路由和动态路由(/analysis/:id)
│                                     # - hash 路由模式
│                                     # - 导航高亮
│
├── index.ts                          # 客户端入口
├── index.css                         # 全局样式(Tailwind + CSS 变量)
└── storage/
    └── database/
        └── shared/
