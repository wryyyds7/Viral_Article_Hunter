# F08 管理后台

| 字段 | 内容 |
|------|------|
| 模块编号 | F08 |
| 模块名称 | 管理后台 |
| 优先级 | P0（用户管理+系统监控）/ P1（配额/API Key/审核）/ P2（配置/日志） |
| 权限要求 | 仅管理员可访问（role = 'admin'） |
| 入口路径 | `/admin` |
| 关联模块 | 所有模块（管理后台是全局管控层） |

---

## 一、模块概述

管理后台是爆文猎人 SaaS 的运维管控中心，为管理员提供用户管理、成本监控、内容安全和系统配置能力。

**核心目标**：
1. **成本可控**：LLM 调用和外部 API 有成本，管理员必须能实时监控和干预
2. **安全合规**：用户上传内容需要审核，违规内容需要及时处理
3. **运维高效**：系统问题能快速定位，用户问题能快速响应

---

## 二、功能清单

### 2.1 用户管理（P0）

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| 用户列表 | 分页展示所有注册用户 | 默认按注册时间倒序，支持按昵称/邮箱搜索 |
| 用户详情 | 查看单个用户的完整信息 | 包含注册时间、用量统计、最近活动、配额使用 |
| 封禁用户 | 禁用某个用户的访问 | 封禁后该用户 Token 立即失效，已有任务终止 |
| 解封用户 | 恢复被封禁用户的访问 | 解封后需重新登录 |
| 角色变更 | 提升或降低用户角色 | 不能删除自己的管理员角色；至少保留一个管理员 |
| 删除用户 | 彻底删除用户及关联数据 | 软删除，数据保留30天后自动清理；需二次确认 |

**UI 交互**：
- 用户列表支持多条件筛选：角色、状态、注册时间范围
- 批量操作：批量封禁/解封（最多50人/次）
- 操作前二次确认弹窗，高风险操作（删除/角色变更）需输入确认文本

### 2.2 系统监控（P0）

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| LLM 调用概览 | 今日/本周/本月的调用次数和 Token 消耗 | 按 LLM Cost 表汇总，支持按天/小时粒度 |
| API 健康状态 | 各外部 API 的可用性和响应时间 | 每5分钟探测一次，超时阈值5秒 |
| 采集成功率 | 最近24小时各平台的采集成功/失败比 | 低于80%标红预警 |
| 实时数据 | 当前在线用户数、进行中的任务数 | 10秒轮询刷新 |
| 成本趋势 | LLM Token 消耗趋势图（日/周/月） | 估算费用 = Token 数 × 单价 |

**UI 交互**：
- 监控大屏布局：顶部核心指标卡片 + 中部趋势图 + 底部状态列表
- 异常指标标红，支持点击查看详情
- 支持导出监控报告（CSV）

### 2.3 配额管理（P1）

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| 配额概览 | 各用户配额使用情况汇总 | 展示：用户 / 日配额 / 已用 / 剩余 / 超限次数 |
| 调整配额 | 修改单个用户的日配额限制 | 支持临时调整（指定天数后恢复）和永久调整 |
| 配额模板 | 按套餐批量设置配额 | 预设 free/pro/enterprise 三档，自定义各维度限制 |
| 超限记录 | 用户配额超限的历史记录 | 用于分析是否需要引导升级套餐 |

**UI 交互**：
- 配额概览支持按使用率排序，超80%的标黄，超95%的标红
- 调整配额支持批量操作

### 2.4 API Key 管理（P1）

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| Key 列表 | 查看已配置的所有外部 API Key | 展示：服务名 / Key前4位 / 状态 / 创建时间 / 最后使用时间 |
| 新增 Key | 添加新的外部 API Key | 支持：红狐数据 / OpenAI / DeepSeek 等 |
| 更新 Key | 替换过期的 Key | 更新后立即生效，不影响进行中的任务 |
| 删除 Key | 移除不再使用的 Key | 删除前检查是否有采集任务依赖该 Key |
| Key 健康检查 | 验证 Key 是否有效 | 定期（每日）自动检查 + 手动触发 |

**安全规则**：
- Key 值脱敏显示（仅显示前4位 + ****）
- 新增/更新 Key 需管理员二次确认
- Key 变更记录写入操作日志
- 禁止通过接口返回完整 Key 值

### 2.5 内容审核（P1）

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| 待审内容 | 用户上传文档中触发安全标记的内容 | LLM 安全检测标记的内容自动进入待审队列 |
| 内容列表 | 查看所有用户的内容（上传/改写） | 支持按用户/时间/类型/状态筛选 |
| 标记违规 | 将内容标记为违规 | 标记后该内容对普通用户不可见 |
| 删除内容 | 删除违规内容 | 软删除，保留审计记录 |
| 解除标记 | 恢复误标记的内容 | 恢复后对用户重新可见 |

**审核流程**：
```
用户上传/改写 → LLM安全检测 → 
  ├─ 安全 → 正常入库
  └─ 疑似违规 → 进入待审队列 → 管理员审核 → 
       ├─ 确认违规 → 标记/删除 + 通知用户
       └─ 误标记 → 解除标记
```

### 2.6 系统配置（P2）

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| 功能开关 | 开启/关闭系统功能模块 | 关闭后该模块入口隐藏，已有数据不受影响 |
| 限流规则 | 调整接口限流参数 | 修改后实时生效 |
| 上传阈值 | 调整文档上传数量阈值 | 默认10篇，可调整为5-50之间 |
| LLM 参数 | 调整模型选择和温度参数 | 影响全局分析/改写质量 |
| 维护模式 | 开启后所有用户看到维护页面 | 管理员仍可访问后台 |

**配置项清单**：

| 配置项 | 默认值 | 范围 | 说明 |
|--------|--------|------|------|
| upload_threshold | 10 | 5-50 | 上传文档自动分析阈值 |
| collect_rate_limit | 10 | 1-60 | 采集接口限流（次/分钟） |
| rewrite_rate_limit | 5 | 1-30 | 改写接口限流（次/分钟） |
| upload_rate_limit | 5 | 1-30 | 上传接口限流（次/分钟） |
| llm_model | deepseek-chat | - | 默认LLM模型 |
| llm_temperature | 0.7 | 0.0-1.0 | 生成温度 |
| llm_max_tokens | 4096 | 1024-8192 | 单次最大输出Token |
| maintenance_mode | false | - | 维护模式开关 |
| content_review_enabled | true | - | 内容审核开关 |

### 2.7 操作日志（P2）

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| 日志列表 | 查看所有管理员操作记录 | 按时间倒序，支持按操作类型/操作人筛选 |
| 日志详情 | 查看单条操作的详细信息 | 包含：操作人/时间/类型/目标/变更前/变更后 |
| 日志导出 | 导出日志为 CSV | 支持按时间范围导出 |
| 日志保留 | 日志自动清理策略 | 默认保留90天 |

**记录范围**：
- 用户管理操作（封禁/解封/角色变更/删除）
- API Key 操作（新增/更新/删除）
- 系统配置变更
- 内容审核操作
- 配额调整

## 三、Agent 主动行为规则（管理后台）

| 节点 | 主动行为 | 话术风格 |
|------|----------|----------|
| LLM 消耗异常 | 日消耗超过日均值3倍时推送通知 | "今日LLM调用量异常偏高，已达到日均的3.2倍，建议检查是否有滥用" |
| API Key 过期 | Key 健康检查失败时推送通知 | "红狐数据API Key已失效，采集功能受影响，请尽快更新" |
| 采集成功率下降 | 低于80%时推送预警 | "小红书采集成功率降至65%，可能需要更换数据源或Key" |
| 新用户注册 | 管理员可选开启通知 | "新用户 zhangsan@example.com 已注册" |
| 内容违规标记 | 自动检测到疑似违规时通知 | "发现1条疑似违规内容，请及时审核" |
| 管理员操作 | 所有管理操作完成后自动记录日志 | 静默记录，不推送 |

## 四、权限与安全

### 4.1 访问控制

| 规则 | 说明 |
|------|------|
| 入口鉴权 | `/admin` 路由前端检查 role=admin，后端中间件强制校验 |
| API 鉴权 | 所有 `/v1/admin/*` 接口必须经过 AdminOnly 中间件 |
| 操作审计 | 所有写操作（POST/PUT/DELETE）必须记录操作日志 |
| 敏感操作 | 封禁用户/删除数据/角色变更需二次确认 |
| Key 安全 | API Key 脱敏存储，接口返回脱敏值 |

### 4.2 安全红线

- 管理员不能查看普通用户的改写原文内容（隐私保护），只能查看元数据和状态
- 管理员不能代替普通用户执行操作（采集/分析/改写）
- 操作日志不可篡改、不可删除
- API Key 变更需双人确认（v2.0）

## 五、非功能需求

| 指标 | 要求 |
|------|------|
| 页面加载 | 管理后台首屏 ≤ 2秒 |
| 数据查询 | 用户列表查询 ≤ 500ms（1万用户以内） |
| 监控数据延迟 | 实时监控数据延迟 ≤ 30秒 |
| 批量操作 | 批量封禁/解封 ≤ 3秒（50人） |
| 并发 | 管理后台接口限流 30次/分钟（独立于普通用户限流） |
