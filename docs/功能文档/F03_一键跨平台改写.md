# 功能文档：一键跨平台改写

| 字段 | 内容 |
|------|------|
| 所属模块 | 跨平台改写 |
| 优先级 | P0（MVP必须） |
| 文档版本 | v1.0 |

---

## 一、功能概述

将选定的爆文素材按照目标平台的内容风格规则进行改写，一次输入可同时输出多个平台版本。改写过程结合头条爆文逻辑（DAIG模型）和各平台风格规则，产出既保留爆款基因又符合平台调性的内容。

---

## 二、用户故事

| 编号 | 用户故事 | 验收条件 |
|------|----------|----------|
| US-R01 | 作为用户，我想从素材库选择一篇爆文作为底稿，以便改写成其他平台版本 | 选择素材后自动填充原文和爆款分析 |
| US-R02 | 作为用户，我想选择改写输出的目标平台，以便一次生成多个版本 | 可勾选7个平台中的任意组合 |
| US-R03 | 作为用户，我想调整改写参数（口语化/emoji/情绪/篇幅），以便控制输出风格 | 4个参数滑块实时调整，生成内容体现差异 |
| US-R04 | 作为用户，我想对生成的内容在线编辑修改，以便微调不满意的部分 | 编辑区支持富文本编辑，修改后可重新导出 |
| US-R05 | 作为用户，我想一键复制或导出生成的内容，以便直接发布到各平台 | 支持复制到剪贴板、导出MD/Word |

## 三、功能需求

### 3.1 素材选择

#### 3.1.1 选择方式

| 入口 | 说明 |
|------|------|
| 素材库跳转 | 在素材库点击"以此为素材创作"，跳转到创作工坊并自动填充 |
| 采集结果跳转 | 在采集结果点击"以此为素材创作"，跳转并自动填充 |
| 创作工坊内选择 | 创作工坊左侧素材选择区搜索并选择 |

#### 3.1.2 素材填充

| 填充项 | 说明 |
|--------|------|
| 原文内容 | 显示素材的完整原文（或摘要） |
| 爆款分析摘要 | 显示标题公式+情绪标签+评分，供参考 |
| 来源平台 | 标注原文来自哪个平台（影响改写方向：从A平台风格转为B平台风格） |

### 3.2 目标平台选择

#### 3.2.1 支持的平台及风格规则

| 平台 | 核心风格规则 |
|------|-------------|
| 小红书 | 至少5个不重复emoji、爆款关键词（好用到哭/建议收藏/绝绝子）、二极管标题法、口语化、末尾Tags、短段落 |
| 公众号 | 深度长文、段落标题清晰、引用/数据支撑、专业感+温度、引导关注 |
| 抖音 | 口播体、开头3秒钩子、短句节奏、互动引导（评论区告诉我）、话题标签 |
| 快手 | 接地气、方言感可选、生活化、亲民语气、兄弟/姐妹称呼 |
| B站 | UP主语气、玩梗、专业+趣味、弹幕互动预埋、节奏感 |
| 知乎 | 逻辑严密、数据/论文引用、观点鲜明、专业术语适当、反直觉开场 |
| 视频号 | 短平快、金句开头、情绪共鸣、社交货币感、引导点赞转发 |

#### 3.2.2 选择规则

| 需求项 | 要求 |
|--------|------|
| 多选 | 复选框，至少选1个平台才能生成 |
| 全选/反选 | 提供快捷按钮 |
| 默认选中 | 小红书+公众号（使用频率最高的两个） |
| 来源排除 | 原文来源平台默认不选中（改写意义不大），但可手动勾选 |

### 3.3 改写参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 口语化程度 | 0-100% | 60% | 0%=正式书面语，100%=纯口语大白话 |
| Emoji密度 | 0-100% | 50% | 0%=无emoji，100%=每句至少1个emoji |
| 情绪强度 | 0-100% | 70% | 0%=理性客观，100%=情绪拉满 |
| 篇幅长度 | 短/中/长 | 中 | 短=200字以内，中=200-500字，长=500-1000字 |

> 参数对不同平台的影响不同：如Emoji密度对知乎改写几乎无影响，对小红书影响大。

### 3.4 生成与编辑

#### 3.4.1 生成流程

| 步骤 | 说明 |
|------|------|
| 1. 参数确认 | 用户选好平台+参数，点击"一键生成" |
| 2. 生成进度 | 显示"正在生成中..."，每个平台独立进度指示 |
| 3. 结果展示 | 每个平台一个Tab页，生成完毕自动切换到第一个Tab |
| 4. 编辑修改 | 用户可在各Tab内直接编辑文本 |
| 5. 重新生成 | 对单个平台点击"重新生成"，仅重新生成该平台版本 |

#### 3.4.2 生成内容结构

每个平台版本的输出包含：

| 字段 | 说明 |
|------|------|
| 标题 | 改写后的标题（含平台风格） |
| 正文 | 改写后的完整正文 |
| 标签/话题 | 平台相关的话题标签（如小红书#话题，抖音#话题） |
| 结构说明 | 标注正文各段落的写作手法（钩子/痛点/方案/号召） |

#### 3.4.3 编辑区功能

| 功能 | 说明 |
|------|------|
| 富文本编辑 | 支持加粗、列表、分段 |
| 字数统计 | 实时显示当前字数 |
| 原文对照 | 可切换"仅改写"和"对照模式"（左原文右改写） |
| 撤销/重做 | 标准编辑器功能 |
| 单平台重新生成 | 不影响其他平台版本 |

### 3.5 导出

| 导出方式 | 说明 |
|----------|------|
| 复制到剪贴板 | 单击即复制当前Tab的内容（含标题+正文+标签） |
| 导出Markdown | 下载为.md文件 |
| 导出Word | 下载为.docx文件 |
| 批量导出 | 将所有平台版本打包为一个文件，各平台分章节 |

## 五、业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-R01 | 爆款基因保留 | 改写必须保留原文的核心爆款元素（标题公式类型、主情绪、核心结构），不可丢失 |
| BR-R02 | 平台规则优先 | 当用户参数与平台规则冲突时，平台规则优先（如知乎不可加emoji，即使emoji密度设100%） |
| BR-R03 | 去重校验 | 改写结果与原文相似度不超过60%，确保不是简单替换词 |
| BR-R04 | 自定义指令 | 用户可在"额外要求"文本框输入补充指令（如"加入个人经历""用第一人称"） |
| BR-R05 | 生成缓存 | 同一素材+同一参数+同一平台的生成结果缓存30分钟，避免重复调用 |
| BR-R06 | 敏感词过滤 | 生成内容自动过滤敏感词/违规表达，替换为安全用语 |

## 十、术语解释

### DAIG模型
头条系内容爆款方法论，由四个维度构成：
- **D（Demand/需求）**：内容是否切中用户的真实需求或痛点
- **A（Arousal/唤醒）**：标题/开头能否迅速抓住注意力，制造"非看不可"的紧迫感
- **I（Identity/认同）**：读者是否产生"这就是我"的身份共鸣，愿意转发表达自我
- **G（Gap/缺口）**：信息是否存在好奇心缺口，驱动用户继续阅读或互动

改写时，系统以DAIG为框架评估原文的爆款基因强度，并在目标平台版本中强化薄弱维度。

### 情绪鸡尾酒
爆文中的情绪组合策略。单一情绪（纯感动/纯愤怒）传播力有限，爆款内容往往是多种情绪的混合搭配，如：
- 愤怒+共情（"凭什么他可以，我却不行"）
- 好奇+焦虑（"月薪3千和3万的人，区别只在这一点"）
- 嫉妒+励志（"同龄人已经年薪百万，你还在犹豫"）

改写系统会识别原文的情绪组合，并在目标平台版本中根据平台调性调整情绪配比。

### 互动钩子
内容中预埋的、引导用户互动的设计元素，包括：
- **提问钩子**：结尾抛出开放问题（"你觉得呢？"）
- **投票钩子**：引导用户选择立场（"你站A还是B？"）
- **话题钩子**：绑定热门话题标签
- **挑战钩子**：激发用户模仿或接力（"来试试你的版本"）

不同平台的互动钩子形式不同（小红书偏话题标签，知乎偏提问，B站偏弹幕梗），改写时自动适配。
