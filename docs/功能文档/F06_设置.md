## 一、功能概述

提供系统级配置入口，包括API Key管理、采集计划配置、改写偏好设置和数据管理。让用户能够个性化定制爆文猎人的行为，确保系统正常运行。

---

## 二、用户故事

| 编号 | 用户故事 | 验收条件 |
|------|----------|----------|
| US-S01 | 作为用户，我想配置各平台的API Key，以便采集功能正常工作 | 配置后采集可正常执行，失效时有提示 |
| US-S02 | 作为用户，我想管理定时采集计划，以便自动化获取热点 | 可新建/编辑/删除/暂停计划 |
| US-S03 | 作为用户，我想设置改写默认参数，以便每次创作不用重复调参数 | 设置后创作工坊默认使用保存的偏好 |
| US-S04 | 作为用户，我想导出全部数据备份，以便防止数据丢失 | 一键导出包含素材库和配置的完整备份 |
| US-S05 | 作为用户，我想清空过期数据，以便释放存储空间 | 可按时间范围删除，需二次确认 |

## 三、功能需求

### 3.1 API Key 配置

#### 3.1.1 配置项

| 配置项 | 说明 | 是否必填 |
|--------|------|----------|
| 红狐数据API Key | 小红书和公众号数据源 | 否（不配置则相关平台不可用） |
| LLM API Key | 改写和分析服务 | 是（核心功能依赖） |
| LLM API Base URL | 自定义模型接口地址 | 否（默认使用系统配置） |

#### 3.1.2 Key管理规则

| 需求项 | 要求 |
|--------|------|
| 输入方式 | 文本框输入，支持粘贴 |
| 显示方式 | 输入后以`sk-****xxxx`掩码显示（仅显示后4位） |
| 校验 | 点击"验证"按钮，调用对应API检测Key有效性 |
| 状态标识 | ✅有效 / ❌无效 / ⚠️未配置 |
| 更新 | 支持覆盖输入新Key |
| 安全 | Key不明文存储，加密入库 |

### 3.2 采集计划配置

> 详见 F01 多平台热点采集 的 3.2 定时采集章节，此处仅列出设置页的入口和管理界面。

| 需求项 | 要求 |
|--------|------|
| 计划列表 | 显示所有已创建的采集计划，含名称/频率/状态/下次执行时间 |
| 操作 | 编辑/删除/暂停/恢复/手动触发 |
| 新建 | 跳转采集计划配置表单 |
| 执行日志 | 点击计划查看该计划的历史执行记录 |

### 3.3 改写偏好设置

#### 3.3.1 默认参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 口语化程度 | 60% | 每次进入创作工坊的默认值 |
| Emoji密度 | 50% | 每次进入创作工坊的默认值 |
| 情绪强度 | 70% | 每次进入创作工坊的默认值 |
| 篇幅长度 | 中 | 每次进入创作工坊的默认值 |
| 默认目标平台 | 小红书+公众号 | 每次进入创作工坊的默认勾选 |

#### 3.3.2 偏好规则

| 规则 | 说明 |
|------|------|
| 保存时机 | 修改后点击"保存"按钮生效 |
| 覆盖范围 | 影响创作工坊的初始值，不影响已有生成结果 |
| 重置 | 提供"恢复默认"按钮 |

### 3.4 数据管理

#### 3.4.1 数据导出

| 需求项 | 要求 |
|--------|------|
| 导出范围 | 全部素材 / 按时间范围选择 |
| 导出内容 | 素材数据（JSON）+ 原文文件（MD）+ 配置备份 |
| 导出格式 | ZIP压缩包 |
| 文件命名 | `爆文猎人_备份_20260604.zip` |

#### 3.4.2 数据导入

| 需求项 | 要求 |
|--------|------|
| 导入来源 | 之前导出的ZIP备份文件 |
| 冲突处理 | 同ID素材选择：覆盖/跳过（默认跳过） |
| 导入校验 | 校验ZIP文件格式和数据完整性 |

#### 3.4.3 数据清理

| 清理方式 | 说明 |
|----------|------|
| 按时间清理 | 选择日期范围，删除该范围内的素材 |
| 按平台清理 | 选择平台，删除该平台的所有素材 |
| 全部清空 | 删除所有数据，需输入"确认清空"后才能执行 |
| 确认机制 | 所有清理操作需二次确认弹窗 |

## 五、业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-S01 | Key验证 | 新输入API Key后必须验证通过才能保存 |
| BR-S02 | Key失效提醒 | 采集时检测到Key失效，在采集日志中标记，并在设置页显示❌ |
| BR-S03 | 必填Key提示 | 首次使用时，未配置LLM API Key则弹出引导"请先配置API Key以使用核心功能" |
| BR-S04 | 偏好即时生效 | 保存改写偏好后，下次进入创作工坊即生效 |
| BR-S05 | 清理不可恢复 | 清理操作弹窗中明确提示"删除后不可恢复" |
| BR-S06 | 导出限流 | 单次导出最大1000条素材 |

---

## 六、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| API Key验证失败 | 提示"验证失败：Key无效或已过期，请检查" |
| 导出文件过大 | 提示"数据量较大，导出可能需要1-2分钟"，异步导出 |
| 导入文件格式错误 | 提示"导入失败：文件格式不正确，请使用爆文猎人导出的备份文件" |
| 导入数据冲突 | 弹窗让用户选择"覆盖已有数据"或"跳过重复数据" |

## 七、依赖关系

| 依赖项 | 说明 |
|--------|------|
| 热点采集模块 | API Key配置影响采集功能可用性 |
| 爆款分析模块 | LLM API Key配置影响分析功能 |
| 跨平台改写模块 | 改写偏好和LLM API Key配置影响改写功能 |
| 素材库模块 | 数据导入导出依赖素材库数据结构 |

## 八、验收标准

| 编号 | 验收标准 |
|------|----------|
| AC-S01 | 配置红狐API Key后点击验证，有效显示✅，无效显示❌ |
| AC-S02 | 未配置LLM Key时，改写功能提示"请先配置API Key" |
| AC-S03 | 保存改写偏好后，进入创作工坊参数为保存值 |
| AC-S04 | 点击导出备份，下载ZIP文件，包含素材和配置 |
| AC-S05 | 导入备份后素材库恢复对应数据 |
| AC-S06 | 清空数据需输入"确认清空"，操作后素材库为空 |
