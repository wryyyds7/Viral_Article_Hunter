# 功能文档：多平台热点采集

| 字段 | 内容 |
|------|------|
| 所属模块 | 热点采集 |
| 优先级 | P0（MVP必须） |
| 文档版本 | v1.0 |

---

## 一、功能概述

从多个内容平台（小红书、公众号、头条等）按关键词采集热门文章/笔记数据，包括标题、摘要、互动数据、发布时间等，为后续爆款分析和改写提供数据源。

---

## 二、用户故事

| 编号 | 用户故事 | 验收条件 |
|------|----------|----------|
| US-C01 | 作为用户，我想输入关键词手动采集热点，以便快速了解某个话题的热门内容 | 输入关键词后10秒内返回结果，结果按热度排序 |
| US-C02 | 作为用户，我想选择采集哪些平台，以便只关注我运营的平台 | 可多选/全选平台，未选平台不采集 |
| US-C03 | 作为用户，我想设置定时采集任务，以便每天自动获取最新热点 | 创建计划后系统按时自动执行，可在日志中查看结果 |
| US-C04 | 作为用户，我想查看采集历史记录，以便回溯之前采集的内容 | 采集日志保留30天，可按日期/状态筛选 |
| US-C05 | 作为用户，我想查看每次采集的执行状态，以便知道采集是否成功 | 每条日志显示成功/失败/部分成功状态及原因 |

---

## 三、功能需求

### 3.1 手动采集

#### 3.1.1 搜索输入

| 需求项 | 要求 |
|--------|------|
| 关键词输入 | 文本框，支持1-50个字符，必填 |
| 关键词类型 | 支持具体词（如"世界杯"）和泛化词（如"减肥"），泛化词提示用户选择细分词 |
| 时间范围 | 下拉选择：近1天/近3天/近7天/近30天，默认近7天 |
| 平台选择 | 多选复选框：小红书/公众号/头条/知乎/B站，默认全选 |
| 采集数量 | 单平台默认返回20条，最大50条 |

#### 3.1.2 采集执行

| 需求项 | 要求 |
|--------|------|
| 执行方式 | 点击"开始采集"后异步执行，显示进度条 |
| 超时设置 | 单平台采集超时15秒，超时返回已有结果并提示 |
| 并发控制 | 多个平台并行采集，非串行 |
| 去重规则 | 同一标题+同一平台视为重复，只保留最新一条 |
| 结果排序 | 默认按热度评分降序，可切换为按时间降序 |

#### 3.1.3 采集结果展示

| 字段 | 说明 |
|------|------|
| 标题 | 文章/笔记标题，可点击进入详情 |
| 平台图标 | 来源平台标识 |
| 热度评分 | 0-100综合评分，含进度条 |
| 互动数据 | 点赞/收藏/评论数（如有） |
| 情绪标签 | 自动分析的情绪类型（1-2个标签） |
| 发布时间 | 原文发布时间 |
| 操作按钮 | [查看详情] [以此为素材创作] [收藏] |

### 3.2 定时采集（P2，MVP后实现）

#### 3.2.1 计划配置

| 配置项 | 要求 |
|--------|------|
| 计划名称 | 文本，1-30字符，必填 |
| 关键词 | 支持多个关键词，逗号分隔 |
| 平台 | 多选 |
| 执行频率 | 每日/每周一/每周三+周五/自定义 |
| 执行时间 | 选择小时:分钟，建议非整点 |
| 启用/禁用 | 开关控制 |

#### 3.2.2 计划管理

| 操作 | 说明 |
|------|------|
| 新建计划 | 填写配置项，保存后立即生效 |
| 编辑计划 | 修改配置，保存后下次执行生效 |
| 删除计划 | 需二次确认 |
| 暂停/恢复 | 不删除，只是暂时停止执行 |
| 手动触发 | 立即执行一次，不等待定时 |

### 3.3 采集日志

| 字段 | 说明 |
|------|------|
| 执行时间 | 采集任务启动的时间 |
| 类型 | 手动/定时 |
| 关键词 | 本次采集的搜索词 |
| 平台 | 本次采集的平台列表 |
| 结果数 | 采集到的文章总数 |
| 状态 | 成功(绿)/部分成功(黄)/失败(红) |
| 失败原因 | 状态非成功时显示原因（API超时/Key失效/无结果等） |
| 操作 | [查看结果] [重新采集] |

## 四、输入输出规格

### 4.1 手动采集接口

**输入：**
```json
{
  "keyword": "世界杯",
  "platforms": ["xiaohongshu", "wechat", "toutiao"],
  "time_range": "7d",
  "limit": 20
}
```

**输出：**
```json
{
  "task_id": "collect_20260604_001",
  "status": "success",
  "total": 45,
  "results": [
    {
      "id": "article_001",
      "title": "世界杯转播权花落小红书！",
      "platform": "xiaohongshu",
      "hotness_score": 98,
      "likes": 12500,
      "collects": 8900,
      "comments": 3200,
      "emotion_tags": ["兴奋", "好奇"],
      "published_at": "2026-06-01T10:30:00+08:00",
      "collected_at": "2026-06-04T11:00:00+08:00",
      "url": "https://..."
    }
  ]
}
```

### 4.2 采集结果数据字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 唯一标识 |
| title | string | 是 | 标题 |
| platform | enum | 是 | xiaohongshu/wechat/toutiao/zhihu/bilibili |
| content | text | 否 | 原文内容（部分平台可获取） |
| summary | text | 否 | 摘要（200字以内） |
| hotness_score | integer | 是 | 热度评分0-100 |
| likes | integer | 否 | 点赞数 |
| collects | integer | 否 | 收藏数 |
| comments | integer | 否 | 评论数 |
| shares | integer | 否 | 分享/转发数 |
| emotion_tags | array | 否 | 情绪标签 |
| published_at | datetime | 否 | 发布时间 |
| collected_at | datetime | 是 | 采集时间 |
| url | string | 否 | 原文链接 |
| author | string | 否 | 作者名称 |
| tags | array | 否 | 原文自带标签 |

## 五、业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-C01 | 关键词去泛化提示 | 当关键词为"减肥""穿搭"等泛化词时，提示"建议选择细分方向，如'减脂餐''职场穿搭'，获取更精准结果" |
| BR-C02 | 重复数据去重 | 同标题+同平台视为重复，更新互动数据和热度评分，不新增记录 |
| BR-C03 | 采集频率限制 | 手动采集：同一关键词10秒内不可重复触发；定时采集：最小间隔24小时 |
| BR-C04 | 空结果处理 | 无结果时显示"未找到相关内容，建议：①更换关键词 ②扩大时间范围 ③检查平台是否可用" |
| BR-C05 | API Key 校验 | 采集前先校验目标平台API Key是否已配置且有效，无效时提示用户前往设置页配置 |

## 六、界面要求

### 6.1 手动采集面板

- 页面顶部：搜索栏（关键词输入+平台选择+时间范围+采集按钮），水平排列
- 搜索栏下方：采集状态提示（"正在采集中..."带进度动画 / "采集完成，共X条"）
- 主体区域：结果列表，卡片式布局，每行一条
- 右上角：排序切换（热度/时间）
- 空状态：提示"输入关键词开始探索热点"

### 6.2 采集日志页

- 表格布局，支持分页（每页20条）
- 状态字段用颜色标签区分
- 支持按状态筛选
- 支持按日期范围筛选

## 七、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| API Key 未配置 | 弹窗提示"请先在设置中配置XX平台API Key"，并提供跳转按钮 |
| API Key 失效 | 采集状态标记为"失败"，失败原因显示"XX平台API Key无效，请检查" |
| 网络超时 | 单平台超时不影响其他平台，已获取的结果正常展示，超时平台标记"采集超时" |
| 接口限流 | 自动重试1次（间隔3秒），仍失败则标记"平台限流，请稍后重试" |
| 无结果 | 显示空状态提示（见业务规则BR-C04） |
| 返回数据格式异常 | 跳过异常数据，记录错误日志，不影响其他数据展示 |

## 八、依赖关系

| 依赖项 | 说明 |
|--------|------|
| 红狐数据API | 小红书和公众号数据源，需配置API Key |
| 联网搜索 | 头条/知乎/B站数据源，无需额外Key |
| 爆款分析模块 | 采集结果需调用分析模块生成热度评分和情绪标签 |
| 素材库模块 | 采集结果自动存入素材库 |

## 九、验收标准

| 编号 | 验收标准 |
|------|----------|
| AC-C01 | 输入关键词"世界杯"，选择小红书+头条，7天范围，点击采集，10秒内返回结果列表 |
| AC-C02 | 结果列表显示标题、平台图标、热度评分、互动数据、情绪标签 |
| AC-C03 | 点击某条结果的"以此为素材创作"，跳转到创作工坊并自动填充该素材 |
| AC-C04 | 未配置API Key时点击采集，弹出配置提示并提供跳转 |
| AC-C05 | 多平台并行采集，某平台超时不影响其他平台结果 |
| AC-C06 | 采集日志记录每次执行的时间、关键词、结果数和状态 |
