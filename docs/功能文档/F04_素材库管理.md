# 功能文档：素材库管理

| 字段 | 内容 |
|------|------|
| 所属模块 | 素材库 |
| 优先级 | P1 |
| 文档版本 | v1.0 |

---

## 一、功能概述

统一管理所有采集到的爆文素材，提供自动归档、标签管理、搜索筛选、收藏和批量操作功能，让用户积累的素材不再零散，形成可持续复用的内容资产库。

---

## 二、用户故事

| 编号 | 用户故事 | 验收条件 |
|------|----------|----------|
| US-L01 | 作为用户，我想看到所有采集过的素材按时间归档，以便有序管理 | 素材自动按采集日期分组 |
| US-L02 | 作为用户，我想给素材打标签，以便分类检索 | 支持自动标签+手动添加自定义标签 |
| US-L03 | 作为用户，我想按关键词/平台/标签/时间搜索素材，以便快速找到需要的内容 | 多维度组合筛选，结果2秒内返回 |
| US-L04 | 作为用户，我想收藏重点素材，以便快速访问 | 收藏夹独立展示，支持取消收藏 |
| US-L05 | 作为用户，我想批量导出素材，以便备份或离线使用 | 支持批量选择后导出为MD/Word |
| US-L06 | 作为用户，我想查看素材的完整详情和分析报告，以便深入了解 | 详情页含原文+4维分析+标签+创作入口 |

---

## 三、功能需求

### 3.1 自动归档

| 需求项 | 要求 |
|--------|------|
| 归档规则 | 采集完成后自动按日期分目录：`素材库/2026-06-04/` |
| 命名规则 | 每条素材自动生成唯一ID，显示名取原标题（截断30字） |
| 重复处理 | 同标题+同平台视为重复，更新互动数据和评分，不新增记录 |
| 存储内容 | 标题、原文/摘要、平台、互动数据、采集时间、分析结果、标签 |

### 3.2 标签管理

#### 3.2.1 标签类型

| 类型 | 来源 | 示例 |
|------|------|------|
| 话题标签 | 采集/上传时自动提取 | 世界杯、减肥、职场 |
| 领域标签 | 采集/上传时自动分类 | 科技、美妆、教育 |
| 平台标签 | 系统自动标注 | 小红书、公众号 |
| 情绪标签 | 爆款分析自动标注 | 兴奋、焦虑、共鸣 |
| 自定义标签 | 用户手动添加 | 重要、待改写、客户需求 |

#### 3.2.2 标签操作

| 操作 | 说明 |
|------|------|
| 添加 | 在素材详情页输入标签名，回车添加 |
| 删除 | 点击标签旁的×删除 |
| 批量打标签 | 列表中多选素材，统一添加标签 |
| 标签云 | 素材库首页显示热门标签云，点击标签筛选 |
| 标签合并 | 将"减肥""瘦身"等同类标签合并为一个 |

### 3.3 搜索与筛选

#### 3.3.1 搜索

| 需求项 | 要求 |
|--------|------|
| 搜索范围 | 标题+正文内容 |
| 搜索方式 | 全文搜索，支持模糊匹配 |
| 搜索建议 | 输入时展示历史搜索记录和热门搜索词 |
| 搜索结果 | 高亮匹配关键词 |

#### 3.3.2 筛选

| 筛选维度 | 选项 |
|----------|------|
| 平台 | 小红书/公众号/头条/知乎/B站，多选 |
| 标签 | 从已有标签中选择，多选 |
| 时间范围 | 今日/近7天/近30天/自定义日期范围 |
| 热度评分 | 滑块选择范围（0-100） |
| 情绪标签 | 从已有情绪标签中选择 |
| 收藏状态 | 仅收藏/全部 |

#### 3.3.3 排序

| 排序方式 | 说明 |
|----------|------|
| 热度降序 | 默认排序 |
| 时间降序 | 最新采集在前 |
| 评分降序 | 爆款评分最高的在前 |

### 3.4 收藏夹

| 需求项 | 要求 |
|--------|------|
| 收藏操作 | 素材卡片/详情页点击⭐图标 |
| 取消收藏 | 再次点击⭐图标 |
| 收藏列表 | 素材库筛选栏增加"仅收藏"开关 |
| 收藏数量 | 不限 |

### 3.5 素材详情页

| 区域 | 内容 |
|------|------|
| 头部 | 标题、来源平台、采集时间、收藏按钮 |
| 原文区 | 完整原文内容（含图片链接如有） |
| 爆款分析区 | 综合评分+雷达图+标题公式+情绪标签+结构模板（复用F02的展示） |
| 标签区 | 自动标签+自定义标签，可编辑 |
| 操作区 | [以此为素材创作] [复制原文] [导出] [删除] |

### 3.6 批量操作

| 操作 | 说明 |
|------|------|
| 批量选择 | 列表中勾选多条素材 |
| 批量打标签 | 选中后统一添加标签 |
| 批量导出 | 选中后导出为单个MD/Word文件 |
| 批量删除 | 选中后删除，需二次确认 |

## 五、业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-L01 | 采集/上传自动入库 | 采集结果和上传文档解析后自动存入素材库，不需要手动操作 |
| BR-L02 | 去重更新 | 同标题+同平台重复采集时，更新互动数据和评分，保留用户自定义标签 |
| BR-L03 | 删除确认 | 删除素材需二次确认，单条和批量均需确认 |
| BR-L04 | 标签上限 | 单条素材最多20个标签（含自动+自定义） |
| BR-L05 | 导出格式 | MD导出含YAML Front Matter（标题/平台/标签/评分）；Word导出含分析摘要页 |
| BR-L06 | 数据保留 | 素材永久保留，不自动清理（用户手动删除） |

## 六、界面要求

### 6.1 素材库首页

- 顶部：搜索框 + 筛选条件栏（平台/标签/时间/评分/收藏）+ 排序下拉
- 中部：标签云（横排，字号按使用频率）
- 主体：素材卡片网格（3列）或列表（单列），支持切换
- 每张卡片：标题（1行截断）+ 平台图标 + 评分圆点 + 2个情绪标签 + 收藏星标 + 时间
- 右上角：视图切换（网格/列表）+ 批量操作按钮
- 底部：分页器

### 6.2 素材详情页

- 面包屑导航：素材库 > 2026-06-04 > 文章标题
- 左侧(60%)：原文内容区
- 右侧(40%)：分析报告 + 标签编辑区
- 底部：操作按钮栏

## 七、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 搜索无结果 | 显示"未找到匹配素材，试试减少筛选条件" |
| 标签已存在 | 添加重复标签时忽略，不报错 |
| 导出失败 | 提示"导出失败，请重试"，不丢失数据 |
| 删除后恢复 | 不支持恢复，删除确认弹窗中提示"删除后不可恢复" |
