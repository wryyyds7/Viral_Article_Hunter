# 功能文档：数据看板

| 字段 | 内容 |
|------|------|
| 所属模块 | 数据看板 |
| 优先级 | P1 |
| 文档版本 | v1.0 |

---

## 一、功能概述

以可视化图表形式呈现热点趋势、平台对比、话题分布和个人创作统计，帮助用户从数据角度理解内容生态、把握创作时机。

---

## 二、用户故事

| 编号 | 用户故事 | 验收条件 |
|------|----------|----------|
| US-D01 | 作为用户，我想看到今日各平台TOP5热文，以便快速了解当天热点 | 首页展示5张热文卡片，可切换平台 |
| US-D02 | 作为用户，我想看到近7天/30天的话题热度走势，以便判断热点是在涨还是退 | 折线图展示趋势，支持切换时间范围 |
| US-D03 | 作为用户，我想看到同一话题在不同平台的表现差异，以便决定优先发哪个平台 | 对比表格展示互动数据和评分差异 |
| US-D04 | 作为用户，我想看到热门话题词云，以便发现新兴话题 | 词云图，字号代表频次，可点击筛选 |
| US-D05 | 作为用户，我想看到自己的创作统计，以便了解产出和覆盖情况 | 统计卡片展示篇数/平台分布/趋势 |

---

## 三、功能需求

### 3.1 今日热点速览

| 需求项 | 要求 |
|--------|------|
| 展示内容 | 各平台TOP5热文卡片 |
| 平台切换 | Tab切换：全部/小红书/公众号/头条/知乎/B站 |
| 卡片信息 | 排名序号+标题+平台图标+热度评分+情绪标签 |
| 点击交互 | 点击卡片跳转素材详情 |
| 刷新频率 | 每次打开首页重新加载 |
| 空状态 | 今日未采集时显示"暂无今日数据，点击[立即采集]" |

### 3.2 趋势图表

#### 3.2.1 热度走势图

| 需求项 | 要求 |
|--------|------|
| 图表类型 | 折线图 |
| X轴 | 日期（近7天/近30天，可切换） |
| Y轴 | 平均热度评分 |
| 数据系列 | 各平台分别一条线，可勾选显示/隐藏 |
| 交互 | 悬浮显示具体数值，点击日期查看当日详情 |
| 数据来源 | 基于素材库中已有数据的日均值 |

#### 3.2.2 话题热度排行

| 需求项 | 要求 |
|--------|------|
| 展示内容 | 近7天热度最高的10个话题关键词 |
| 排序 | 按相关文章数×平均热度综合排序 |
| 交互 | 点击话题关键词跳转搜索结果 |
| 趋势标记 | 每个话题标注↑上升/↓下降/→平稳 |

### 3.3 平台对比

#### 3.3.1 同话题对比表

| 需求项 | 要求 |
|--------|------|
| 触发方式 | 在素材详情页点击"查看同话题跨平台表现" |
| 对比维度 | 平均互动数（点赞/收藏/评论）、平均评分、文章数量 |
| 展示形式 | 表格+柱状图 |
| 数据范围 | 与当前素材话题标签相同的内容 |

#### 3.3.2 平台概览

| 需求项 | 要求 |
|--------|------|
| 展示内容 | 各平台的素材总量、平均评分、最近采集时间 |
| 展示形式 | 卡片式，每个平台一张 |
| 状态标记 | 超过3天未采集的平台标记"数据过期" |

### 3.4 话题词云

| 需求项 | 要求 |
|--------|------|
| 数据来源 | 素材库中所有标签和关键词的频次统计 |
| 展示形式 | 词云图，字号=频次×平均热度 |
| 颜色 | 按情绪标签着色（正面=暖色，负面=冷色，混合=紫色） |
| 交互 | 点击词语跳转搜索该标签的素材 |
| 时间筛选 | 近7天/近30天/全部 |

### 3.5 个人创作统计

| 需求项 | 要求 |
|--------|------|
| 总生成篇数 | 累计改写生成的文章数 |
| 平台分布 | 各平台生成篇数饼图 |
| 近7天趋势 | 每日生成篇数折线图 |
| 最常用参数 | 口语化/emoji/情绪/篇幅的常用设置 |
| 高产日 | 生成篇数最多的日期 |

## 五、业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-D01 | 数据来源 | 所有看板数据来源于素材库，非实时外部数据 |
| BR-D02 | 缓存策略 | 看板数据缓存5分钟，避免频繁查询 |
| BR-D03 | 空数据处理 | 无素材时各图表显示空状态图+引导文案 |
| BR-D04 | 最低数据量 | 趋势图至少需要2天数据，不足时显示"数据不足，采集2天后即可查看趋势" |
