# 功能文档：爆款基因分析

| 字段 | 内容 |
|------|------|
| 所属模块 | 爆款分析 |
| 优先级 | P0（MVP必须） |
| 文档版本 | v1.0 |

---

## 一、功能概述

对采集到的文章/笔记进行自动化爆款因素拆解，包括标题公式识别、情绪标签标注、爆款因子综合评分、内容结构模板提取。让用户不仅看到"什么火"，还能理解"为什么火"和"怎么复制"。

---

## 二、用户故事

| 编号 | 用户故事 | 验收条件 |
|------|----------|----------|
| US-A01 | 作为用户，我想看到每篇文章的标题使用了什么爆款公式，以便学习模仿 | 每篇文章标注1-2种标题公式类型 |
| US-A02 | 作为用户，我想知道文章传递的核心情绪，以便把握内容调性 | 自动标注1-3个情绪标签 |
| US-A03 | 作为用户，我想看到文章的爆款评分，以便快速筛选最有价值的素材 | 0-100综合评分，与采集列表联动 |
| US-A04 | 作为用户，我想看到文章的内容结构模板，以便模仿其写作框架 | 提取并展示文章的段落结构模板 |
| US-A05 | 作为用户，我想在素材详情页看到完整的分析报告，以便深入理解爆款逻辑 | 详情页包含4维分析+综合评价 |

## 三、功能需求

### 3.1 标题公式识别

#### 3.1.1 支持的标题公式类型

| 公式类型 | 说明 | 示例 |
|----------|------|------|
| 二极管法 | 极端对比制造冲突 | "千万别XX，否则XX" |
| 数字法 | 用具体数字增强可信度 | "3个方法让你XX" "99%的人不知道" |
| 悬念法 | 制造信息差引发好奇 | "原来XX的真相是..." "我发现了..." |
| 反常识法 | 颠覆常规认知 | "越努力越穷？因为..." |
| 身份法 | 点名特定人群 | "给30岁女性的XX建议" |
| 痛点法 | 直击用户焦虑/困难 | "熬夜党必看！" "打工人XX" |
| 利益法 | 直接许诺收益 | "这样做，月入X万" |
| 情绪法 | 用情绪词驱动点击 | "好用到哭！" "绝绝子" |

#### 3.1.2 识别规则

| 需求项 | 要求 |
|--------|------|
| 识别数量 | 每个标题识别1-2种公式，按置信度排序 |
| 置信度 | 输出每种公式的匹配置信度（0-100%） |
| 公式拆解 | 高亮标题中匹配公式的关键词部分 |
| 批量识别 | 采集结果列表支持批量自动识别，不需要逐篇触发 |

### 3.2 情绪标签标注

#### 3.2.1 支持的情绪类型

| 一级分类 | 二级标签 | 说明 |
|----------|----------|------|
| 正面 | 兴奋、感动、共鸣、爽感、好奇 | 积极情绪驱动 |
| 负面 | 焦虑、愤怒、恐惧、厌恶、悲伤 | 负面情绪触发 |
| 混合 | 期待、纠结、矛盾 | 多重情绪叠加 |

#### 3.2.2 标注规则

| 需求项 | 要求 |
|--------|------|
| 标注数量 | 每篇文章标注1-3个情绪标签，按强度排序 |
| 强度评级 | 每个标签附带强度：强/中/弱 |
| 分析依据 | 基于标题+正文内容+互动数据综合判断 |
| 主情绪 | 排名第一的标签标记为"主情绪"，在列表中以高亮展示 |

### 3.3 爆款因子评分

#### 3.3.1 评分维度与权重

| 维度 | 权重 | 评估内容 |
|------|------|----------|
| 标题力 | 30% | 标题是否使用爆款公式、点击欲望强度 |
| 情绪密度 | 25% | 情绪标签数量和强度、情绪共鸣度 |
| 互动钩子 | 25% | 是否预埋互动点（提问/投票/话题标签） |
| 结构密度 | 20% | 内容结构是否模块化、信息密度是否高 |

#### 3.3.2 评分规则

| 需求项 | 要求 |
|--------|------|
| 评分范围 | 0-100，取整数 |
| 评分等级 | 90+爆款 / 70-89高潜 / 50-69一般 / 50以下低潜 |
| 展示形式 | 数字+彩色进度条（绿=爆款/蓝=高潜/黄=一般/灰=低潜） |
| 维度拆分 | 详情页展示各维度独立评分和雷达图 |
| 实时更新 | 互动数据变化时重新计算（仅定时采集触发，非实时） |

### 3.4 结构模板提取

#### 3.4.1 支持的结构模板

| 模板类型 | 说明 | 典型结构 |
|----------|------|----------|
| 痛点-方案 | 先讲痛点再给解法 | 痛点描述→原因分析→解决方案→行动号召 |
| 故事-启发 | 叙事+感悟 | 开头场景→冲突展开→转折→感悟总结 |
| 盘点-清单 | 罗列式内容 | 引入→项目1→项目2→...→总结 |
| 对比-测评 | A vs B | 评测背景→维度1对比→维度2对比→结论 |
| 教程-步骤 | 手把手教学 | 目标说明→步骤1→步骤2→...→效果展示 |
| 观点-论证 | 先抛观点再论证 | 核心观点→论据1→论据2→反证→结论 |

#### 3.4.2 提取规则

| 需求项 | 要求 |
|--------|------|
| 识别方式 | 基于段落结构和逻辑词自动识别 |
| 段落拆分 | 将原文拆分为语义段落，标注每段的功能角色 |
| 模板匹配 | 输出最匹配的1种模板及匹配度 |
| 可视化 | 以流程图/骨架图展示文章结构 |

## 五、业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-A01 | 采集/上传即分析 | 采集完成或文档上传（且数量达标）后自动触发分析，不需要用户手动操作；分析为异步执行，通过任务ID查询进度 |
| BR-A02 | 评分一致性 | 同一文章多次分析评分偏差不超过±3分 |
| BR-A03 | 短内容容错 | 内容少于50字的文章，结构模板标记为"内容过短，无法提取" |
| BR-A04 | 分析结果可修正 | 用户可手动修改情绪标签和标题公式（系统标注+用户修正模式） |
| BR-A05 | 批量分析上限 | 单次批量分析不超过50篇文章 |

## 六、界面要求

### 6.1 列表中的分析摘要

- 热度评分：数字+彩色圆点（绿/蓝/黄/灰）
- 情绪标签：1-2个彩色标签胶囊
- 标题公式：小型灰色标签

### 6.2 素材详情页-分析报告

- 上方：综合评分（大字号数字+等级标签+圆形进度环）
- 中左：四维雷达图（标题力/情绪密度/互动钩子/结构密度）
- 中右：标题公式卡片（公式类型+匹配词高亮+置信度）
- 下方左：情绪标签（主情绪高亮+强度条）
- 下方右：结构模板图（流程图形式展示段落角色）
- 底部：[修正分析] 按钮

---

## 七、异常处理

| 异常场景 | 处理方式 |
|----------|----------|
| 内容为空 | 评分置为0，标注"无内容可分析" |
| 分析超时 | 跳过该篇，记录日志，不影响批量中其他文章 |
| LLM返回格式异常 | 重试1次，仍异常则仅输出可解析的部分+标记"分析不完整" |
| 无法识别标题公式 | 标注"常规标题"，置信度为0 |
