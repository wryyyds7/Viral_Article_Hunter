# 接口文档：一键跨平台改写

| 字段 | 内容 |
|------|------|
| 模块 | 跨平台改写 |
| 文档版本 | v1.0 |
| 更新日期 | 2026-06-04 |

> 所有接口遵循 [A00_公共接口规范](A00_公共接口规范.md) 的请求/响应格式和错误码规范。

---

## 一、接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /rewrite/generate | 一键生成跨平台改写 |
| GET | /rewrite/tasks/{task_id} | 获取改写任务状态与结果 |
| PUT | /rewrite/tasks/{task_id}/platforms/{platform} | 修改某平台版本内容 |
| POST | /rewrite/tasks/{task_id}/platforms/{platform}/regenerate | 重新生成某平台版本 |
| GET | /rewrite/platforms | 获取平台改写规则列表 |
| GET | /rewrite/platforms/{platform}/rules | 获取单个平台详细规则 |
| POST | /rewrite/export | 导出改写结果 |
| GET | /rewrite/history | 获取改写历史列表 |

## 二、接口详情

### 2.1 POST /rewrite/generate

触发跨平台改写生成。

**请求体：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| article_id | string | 是 | — | 源素材ID |
| target_platforms | string[] | 是 | — | 目标平台列表，值见枚举6.1，至少1个 |
| params | RewriteParams | 否 | 用户偏好 | 改写参数 |
| custom_instruction | string | 否 | "" | 额外改写指令（200字内） |

**RewriteParams 结构：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| colloquial | integer | 否 | 60 | 口语化程度0-100 |
| emoji_density | integer | 否 | 50 | Emoji密度0-100 |
| emotion_intensity | integer | 否 | 70 | 情绪强度0-100 |
| length | string | 否 | medium | 篇幅：short/medium/long |

**请求示例：**

```json
{
  "article_id": "article_001",
  "target_platforms": ["wechat", "douyin", "zhihu"],
  "params": {
    "colloquial": 60,
    "emoji_density": 50,
    "emotion_intensity": 70,
    "length": "medium"
  },
  "custom_instruction": "加入个人经历视角"
}
```

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.task_id | string | 改写任务ID |
| data.status | string | 任务状态：pending/processing/completed/partial/failed |
| data.platforms | PlatformStatus[] | 各平台处理状态 |

**PlatformStatus 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| platform | string | 平台枚举值 |
| status | string | 状态：pending/processing/completed/failed |
| estimated_seconds | integer | 预估等待秒数（仅processing时） |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "rewrite_20260604_001",
    "status": "processing",
    "platforms": [
      {"platform": "wechat", "status": "processing", "estimated_seconds": 12},
      {"platform": "douyin", "status": "pending", "estimated_seconds": 15},
      {"platform": "zhihu", "status": "pending", "estimated_seconds": 18}
    ]
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40301 | 未选择素材（article_id为空） |
| 40302 | 未选择目标平台 |
| 40303 | 素材不存在 |
| 40304 | 参数超出范围 |
| 40305 | LLM API Key未配置 |
| 42901 | 改写频率超限（5次/分钟） |

### 2.3 PUT /rewrite/tasks/{task_id}/platforms/{platform}

修改某平台版本的改写内容（用户手动编辑）。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| task_id | string | 改写任务ID |
| platform | string | 平台枚举值 |

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 否 | 修改后的标题 |
| content | string | 否 | 修改后的正文 |
| tags | string[] | 否 | 修改后的标签 |

> 至少传一个字段。

**请求示例：**

```json
{
  "title": "小红书拿下世界杯转播权！这波操作绝了",
  "content": "姐妹们！！！世界杯转播权居然被小红书拿下了！！！\n\n这意味着我们可以边看球边种草了😂\n\n..."
}
```

**响应体：**

返回该平台修改后的完整 RewriteResult（同 2.2 中 results 内的单个平台对象），`is_modified` 为 `true`，`word_count` 重新计算。

---

### 2.4 POST /rewrite/tasks/{task_id}/platforms/{platform}/regenerate

重新生成某平台版本的改写内容（不影响其他平台）。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| task_id | string | 改写任务ID |
| platform | string | 平台枚举值 |

**请求体：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| params | RewriteParams | 否 | 原参数 | 新的改写参数（覆盖原参数） |
| custom_instruction | string | 否 | 原指令 | 新的额外指令 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.task_id | string | 任务ID（不变） |
| data.platform | string | 平台 |
| data.status | string | 状态：processing |
| data.estimated_seconds | integer | 预估秒数 |

> 重新生成后需再次调用 GET /rewrite/tasks/{task_id} 获取新结果。

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40306 | LLM服务不可用 |
| 40307 | 生成超时 |

### 2.6 GET /rewrite/platforms/{platform}/rules

获取单个平台的详细改写规则。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| platform | string | 平台枚举值 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.platform | string | 平台枚举值 |
| data.display | string | 中文名 |
| data.rules | PlatformRule[] | 规则列表 |
| data.examples | RewriteExample[] | 改写示例 |

**PlatformRule 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| category | string | 规则分类（标题/正文/标签/语气/格式） |
| rule | string | 规则描述 |
| priority | string | 优先级：required/recommended/optional |
| example | string | 示例 |

**RewriteExample 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| source_title | string | 原始标题 |
| rewritten_title | string | 改写后标题 |
| source_excerpt | string | 原文片段 |
| rewritten_excerpt | string | 改写后片段 |

**响应示例：**

```json
{

  "message": "success",
```

### 2.7 POST /rewrite/export

导出改写结果。

**请求体：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| task_id | string | 是 | — | 改写任务ID |
| platforms | string[] | 否 | 全部已完成 | 导出的平台列表 |
| format | string | 否 | markdown | 导出格式：markdown/docx |

**响应：**

文件下载流。

| 格式 | Content-Type | 文件名 |
|------|-------------|--------|
| markdown | application/octet-stream | `爆文改写_{article_id}_{date}.md` |
| docx | application/vnd.openxmlformats-officedocument.wordprocessingml.document | `爆文改写_{article_id}_{date}.docx` |

**Markdown导出格式：**

```markdown
---
source: 世界杯转播权花落小红书！
source_platform: 小红书
created_at: 2026-06-04
---

# 公众号版本

## 小红书拿下2026世界杯转播权，内容平台的天花板在哪？

正文内容...

标签：世界杯, 内容平台, 小红书

---

# 抖音版本

## 世界杯转播权被小红书拿了！评论区炸了

正文内容...

标签：#世界杯 #小红书 #转播权

---
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40303 | 任务不存在 |
| 40307 | 任务尚未完成，无结果可导出 |

### 2.8 GET /rewrite/history

获取改写历史列表。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | integer | 否 | 1 | 页码 |
| page_size | integer | 否 | 20 | 每页条数 |
| platform | string | 否 | — | 按目标平台筛选 |
| date_from | string | 否 | — | 起始日期 |
| date_to | string | 否 | — | 结束日期 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[].task_id | string | 任务ID |
| data.items[].source_title | string | 源素材标题 |
| data.items[].source_platform | string | 来源平台 |
| data.items[].target_platforms | string[] | 目标平台 |
| data.items[].status | string | 任务状态 |
| data.items[].created_at | string | 创建时间 |
| data.total | integer | 总条数 |
| data.page | integer | 当前页码 |
| data.page_size | integer | 每页条数 |

**响应示例：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "task_id": "rt_1a2b3c",
        "source_title": "10个职场沟通技巧，让你少走弯路",
        "source_platform": "xiaohongshu",
        "target_platforms": ["wechat_mp", "zhihu", "bilibili"],
        "status": "completed",
        "created_at": "2026-06-04T14:30:00+08:00"
      }
    ],
    "total": 35,
    "page": 1,
    "page_size": 20
  }
}
```

**错误码：**

| 错误码 | 说明 |
|--------|------|
| 40101 | 未认证 |
| 40302 | 数据越权（访问他人改写记录） |
| data.pagination | Pagination | 分页信息 |
