# 接口文档：多平台热点采集

| 字段 | 内容 |
|------|------|
| 模块 | 热点采集 |
| 文档版本 | v1.0 |
| 更新日期 | 2026-06-04 |

> 所有接口遵循 [A00_公共接口规范](A00_公共接口规范.md) 的请求/响应格式和错误码规范。

---

## 一、接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /collect/manual | 手动采集 |
| GET | /collect/tasks | 获取采集任务列表 |
| GET | /collect/tasks/{task_id} | 获取采集任务详情（含结果） |
| POST | /collect/schedules | 创建定时采集计划 |
| GET | /collect/schedules | 获取定时采集计划列表 |
| PUT | /collect/schedules/{schedule_id} | 更新定时采集计划 |
| DELETE | /collect/schedules/{schedule_id} | 删除定时采集计划 |
| POST | /collect/schedules/{schedule_id}/toggle | 启用/暂停计划 |
| POST | /collect/schedules/{schedule_id}/trigger | 手动触发计划 |
| GET | /collect/logs | 获取采集日志 |

## 二、接口详情

### 2.1 POST /collect/manual

手动触发采集任务。

**请求体：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| keyword | string | 是 | — | 搜索关键词，1-50字符 |
| platforms | string[] | 否 | 全部平台 | 采集平台列表，值见枚举6.1 |
| time_range | string | 否 | 7d | 时间范围：1d/3d/7d/30d |
| limit | integer | 否 | 20 | 单平台返回数量，范围1-50 |

**请求示例：**

```json
{
  "keyword": "世界杯",
  "platforms": ["xiaohongshu", "toutiao"],
  "time_range": "7d",
  "limit": 20
}
```

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.task_id | string | 采集任务ID |
| data.status | string | 任务状态：pending/running/success/partial/failed |
| data.total | integer | 采集结果总数 |
| data.results | ArticleSummary[] | 采集结果列表（按热度降序） |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "task_20260604_001",
    "status": "success",
    "total": 35,
    "results": [
      {
        "id": "article_001",
        "title": "世界杯转播权花落小红书！",
        "platform": "xiaohongshu",
        "hotness_score": 98,
        "hotness_level": "viral",
        "emotion_tags": [
          {"tag": "excitement", "level": "strong", "is_primary": true}
        ],
        "title_formulas": [
          {"type": "emotion", "confidence": 0.92}
        ],
        "interaction": {
          "likes": 12500,
          "collects": 8900,
          "comments": 3200,
          "shares": null
        },
        "published_at": "2026-06-01T10:30:00+08:00",
        "collected_at": "2026-06-04T11:00:00+08:00",
        "is_favorited": false,
        "tags": ["世界杯"]
      }
    ]
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 41101 | 关键词为空 |
| 41102 | 平台参数无效 |
| 41103 | 时间范围无效 |
| 41104 | API Key未配置 |
| 41105 | API Key无效 |
| 42901 | 采集频率超限（同一关键词10秒内不可重复） |

### 2.2 GET /collect/tasks

获取采集任务列表。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | integer | 否 | 1 | 页码 |
| page_size | integer | 否 | 20 | 每页条数 |
| status | string | 否 | — | 按状态筛选：success/partial/failed |
| date_from | string | 否 | — | 起始日期 YYYY-MM-DD |
| date_to | string | 否 | — | 结束日期 YYYY-MM-DD |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[].task_id | string | 任务ID |
| data.items[].keyword | string | 搜索关键词 |
| data.items[].platforms | string[] | 采集平台 |
| data.items[].status | string | 任务状态 |
| data.items[].total | integer | 结果数量 |
| data.items[].created_at | string | 创建时间 |
| data.items[].finished_at | string | 完成时间 |
| data.items[].error_message | string | 失败原因（仅失败时） |
| data.pagination | Pagination | 分页信息 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "task_id": "task_20260604_001",
        "keyword": "世界杯",
        "platforms": ["xiaohongshu", "toutiao"],
        "status": "success",
        "total": 35,
        "created_at": "2026-06-04T11:00:00+08:00",
        "finished_at": "2026-06-04T11:00:08+08:00",
        "error_message": null
      }
    ],
    "pagination": {
      "page": 1,
      "page_size": 20,
      "total": 12,
      "total_pages": 1
    }
  }
}
```

### 2.3 GET /collect/tasks/{task_id}

获取采集任务详情，包含完整结果列表。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| task_id | string | 采集任务ID |

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | integer | 否 | 1 | 结果分页页码 |
| page_size | integer | 否 | 20 | 每页条数 |
| sort_by | string | 否 | hotness_score | 排序字段：hotness_score/collected_at |
| sort_order | string | 否 | desc | 排序方向：asc/desc |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.task_id | string | 任务ID |
| data.keyword | string | 搜索关键词 |
| data.platforms | string[] | 采集平台 |
| data.status | string | 任务状态 |
| data.results | ArticleSummary[] | 采集结果列表 |
| data.pagination | Pagination | 分页信息 |

### 2.4 POST /collect/schedules

创建定时采集计划。

**请求体：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| name | string | 是 | — | 计划名称，1-30字符 |
| keyword | string | 是 | — | 搜索关键词 |
| platforms | string[] | 否 | 全部平台 | 采集平台 |
| frequency | string | 是 | — | 执行频率：daily/weekly/custom |
| execute_time | string | 是 | — | 执行时间 HH:mm（建议非整点） |
| custom_cron | string | 条件必填 | — | frequency=custom时必填，cron表达式 |
| enabled | boolean | 否 | true | 是否立即启用 |

**请求示例：**

```json
{
  "name": "世界杯热点追踪",
  "keyword": "世界杯",
  "platforms": ["xiaohongshu", "toutiao"],
  "frequency": "daily",
  "execute_time": "09:30",
  "enabled": true
}
```

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.schedule_id | string | 计划ID |
| data.name | string | 计划名称 |
| data.keyword | string | 搜索关键词 |
| data.platforms | string[] | 采集平台 |
| data.frequency | string | 执行频率 |
| data.execute_time | string | 执行时间 |
| data.enabled | boolean | 是否启用 |
| data.next_execute_at | string | 下次执行时间 |
| data.created_at | string | 创建时间 |

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 41111 | 计划名称为空 |
| 41112 | 关键词为空 |
| 41113 | 执行频率无效 |

---

### 2.5 GET /collect/schedules

获取定时采集计划列表。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| enabled | boolean | 否 | — | 按启用状态筛选 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[].schedule_id | string | 计划ID |
| data.items[].name | string | 计划名称 |
| data.items[].keyword | string | 搜索关键词 |
| data.items[].platforms | string[] | 采集平台 |
| data.items[].frequency | string | 执行频率 |
| data.items[].execute_time | string | 执行时间 |
| data.items[].enabled | boolean | 是否启用 |
| data.items[].next_execute_at | string | 下次执行时间 |
| data.items[].last_execute_at | string | 上次执行时间 |
| data.items[].last_status | string | 上次执行状态 |
| data.items[].created_at | string | 创建时间 |

---

### 2.6 PUT /collect/schedules/{schedule_id}

更新定时采集计划。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| schedule_id | string | 计划ID |

**请求体：**

与创建接口相同，所有字段可选。仅传需要修改的字段。

**响应体：**

与创建接口响应体相同，返回更新后的完整计划信息。

---

### 2.7 DELETE /collect/schedules/{schedule_id}

删除定时采集计划（不可恢复）。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| schedule_id | string | 计划ID |

**响应体：**

```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```

---

### 2.8 POST /collect/schedules/{schedule_id}/toggle

启用或暂停采集计划。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| schedule_id | string | 计划ID |

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| enabled | boolean | 是 | true=启用，false=暂停 |

**响应体：**

返回更新后的完整计划信息（同创建接口响应体）。

---

### 2.9 POST /collect/schedules/{schedule_id}/trigger

手动触发一次采集计划执行（不影响定时调度）。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| schedule_id | string | 计划ID |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.task_id | string | 触发生成的采集任务ID |
| data.status | string | 任务状态 |

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 42901 | 该计划10秒内已触发过 |

---

### 2.10 GET /collect/logs

获取采集执行日志。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| page | integer | 否 | 1 | 页码 |
| page_size | integer | 否 | 20 | 每页条数 |
| status | string | 否 | — | 按状态筛选 |
| source_type | string | 否 | — | 触发类型：manual/scheduled |
| date_from | string | 否 | — | 起始日期 |
| date_to | string | 否 | — | 结束日期 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[].log_id | string | 日志ID |
| data.items[].task_id | string | 关联任务ID |
| data.items[].source_type | string | 触发类型：manual/scheduled |
| data.items[].schedule_name | string | 计划名称（仅定时任务） |
| data.items[].keyword | string | 搜索关键词 |
| data.items[].platforms | string[] | 采集平台 |
| data.items[].result_count | integer | 结果数量 |
| data.items[].status | string | 执行状态 |
| data.items[].error_message | string | 失败原因 |
| data.items[].started_at | string | 开始时间 |
| data.items[].finished_at | string | 结束时间 |
| data.items[].duration_ms | integer | 耗时（毫秒） |
| data.pagination | Pagination | 分页信息 |
