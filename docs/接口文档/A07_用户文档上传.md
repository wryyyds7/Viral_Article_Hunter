# 接口文档：用户文档上传

| 字段 | 内容 |
|------|------|
| 模块 | 用户文档上传 |
| 文档版本 | v1.0 |
| 更新日期 | 2026-06-04 |

> 所有接口遵循 [A00_公共接口规范](A00_公共接口规范.md) 的请求/响应格式和错误码规范。
> 所有上传接口均需认证（`Authorization: Bearer <access_token>`），上传数据为用户私有。

---

## 一、接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /upload/documents | 批量上传文档 |
| GET | /upload/documents/{batch_id} | 获取上传批次详情 |
| POST | /upload/documents/{batch_id}/retry | 重新上传失败文件 |
| POST | /upload/documents/{batch_id}/analyze | 触发爆款分析 |
| GET | /upload/documents/{batch_id}/status | 获取批量上传处理进度 |

---

## 二、接口详情

### 2.1 POST /upload/documents

批量上传文档文件。采用 `multipart/form-data` 格式。

**请求：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| files | file[] | 是 | — | 文档文件列表，单次最多20个 |
| auto_analyze | boolean | 否 | true | 上传完成后是否自动触发分析 |

**请求示例：**

```
POST /upload/documents
Content-Type: multipart/form-data

files: [article1.txt, article2.docx, article3.pdf]
auto_analyze: true
```

**校验规则：**

| 校验项 | 规则 | 失败处理 |
|--------|------|----------|
| 文件数量 | ≤ 20 | 超出部分拒绝，返回错误提示 |
| 单文件大小 | ≤ 5MB | 超出文件拒绝，其余正常处理 |
| 文件格式 | `.txt/.md/.docx/.pdf/.html` | 不支持的格式拒绝 |
| 批量总大小 | ≤ 50MB | 超出时返回错误，要求减少文件 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.batch_id | string | 上传批次ID |
| data.total | integer | 提交文件总数 |
| data.accepted | integer | 接受上传的文件数 |
| data.rejected | integer | 拒绝的文件数 |
| data.rejected_files | RejectedFile[] | 被拒绝的文件及原因 |
| data.processing | boolean | 是否正在解析中 |

**RejectedFile 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| filename | string | 文件名 |
| reason | string | 拒绝原因：unsupported_format / file_too_large / batch_size_exceeded |

**响应示例（部分文件被拒绝）：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "batch_id": "batch_20260604_001",
    "total": 3,
    "accepted": 2,
    "rejected": 1,
    "rejected_files": [
      {
        "filename": "image.png",
        "reason": "unsupported_format"
      }
    ],
    "processing": true
  }
}
```

**错误响应示例（批量总大小超限）：**

```json
{
  "code": 40701,
  "message": "批量上传总大小超过50MB限制",
  "data": null
}
```

### 2.2 GET /upload/documents/{batch_id}

获取上传批次的详细处理结果。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| batch_id | string | 上传批次ID |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.batch_id | string | 批次ID |
| data.status | string | 批次状态：processing / completed / partially_completed / failed |
| data.total | integer | 文件总数 |
| data.success_count | integer | 成功解析数 |
| data.failed_count | integer | 解析失败数 |
| data.skipped_count | integer | 跳过数（重复等） |
| data.effective_count | integer | 有效文档数（成功解析且内容≥50字） |
| data.threshold_met | boolean | 是否达到分析阈值（≥10篇） |
| data.files | FileResult[] | 各文件处理结果 |
| data.analyze_triggered | boolean | 是否已触发分析 |
| data.analyze_task_id | string | 分析任务ID（已触发时） |

**FileResult 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| filename | string | 文件名 |
| status | string | 状态：uploading / parsing / success / failed / skipped |
| title | string | 提取的标题（成功时） |
| word_count | integer | 正文字数（成功时） |
| article_id | string | 生成的素材ID（成功时） |
| error | string | 失败原因（失败时） |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "batch_id": "batch_20260604_001",
    "status": "completed",
    "total": 12,
    "success_count": 10,
    "failed_count": 1,
    "skipped_count": 1,
    "effective_count": 10,
    "threshold_met": true,
    "files": [
      {
        "filename": "爆文1-世界杯.txt",
        "status": "success",
        "title": "爆文1-世界杯",
        "word_count": 1520,
        "article_id": "article_upload_001",
        "error": null
      },
      {
        "filename": "扫描件.pdf",
        "status": "failed",
        "title": null,
        "word_count": null,
        "article_id": null,
        "error": "PDF为扫描件，无法提取文字"
      },
      {
        "filename": "重复文章.txt",
        "status": "skipped",
        "title": null,
        "word_count": null,
        "article_id": null,
        "error": "文件内容重复"
      }
    ],
    "analyze_triggered": true,
    "analyze_task_id": "task_20260604_upload_001"
  }
}
```

### 2.3 POST /upload/documents/{batch_id}/retry

重新上传批次中失败的文件。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| batch_id | string | 上传批次ID |

**请求：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| files | file[] | 是 | 需要重新上传的文件（multipart/form-data） |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.batch_id | string | 批次ID（不变） |
| data.retried | integer | 重新上传的文件数 |
| data.success_count | integer | 重新上传后成功的文件数 |
| data.failed_count | integer | 仍然失败的文件数 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "batch_id": "batch_20260604_001",
    "retried": 1,
    "success_count": 1,
    "failed_count": 0
  }
}
```

### 2.4 POST /upload/documents/{batch_id}/analyze

手动触发爆款分析。适用于：
- 数量未达阈值时用户确认"仍然分析"
- 上传时 `auto_analyze=false` 的情况
- 重新上传成功后需要补充分析

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| batch_id | string | 上传批次ID |

**请求体：** 无

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.task_id | string | 分析任务ID |
| data.article_count | integer | 参与分析的文档数 |
| data.status | string | 任务状态：pending / running |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "task_20260604_upload_002",
    "article_count": 7,
    "status": "pending"
  }
}
```

**错误响应（无有效文档）：**

```json
{
  "code": 40703,
  "message": "没有有效的文档可供分析",
  "data": null
}
```

### 2.5 GET /upload/documents/{batch_id}/status

轮询获取批量上传的处理进度（前端可用此接口做进度条更新）。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| batch_id | string | 上传批次ID |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.batch_id | string | 批次ID |
| data.total | integer | 文件总数 |
| data.completed | integer | 已完成处理的文件数（成功+失败+跳过） |
| data.processing | integer | 正在处理的文件数 |
| data.pending | integer | 等待处理的文件数 |
| data.percentage | integer | 处理进度百分比（0-100） |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "batch_id": "batch_20260604_001",
    "total": 12,
    "completed": 8,
    "processing": 2,
    "pending": 2,
    "percentage": 67
  }
}
```

## 三、数据模型

### 3.1 上传批次表 (upload_batches)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 批次ID，格式 `batch_{date}_{seq}` |
| user_id | string | 所属用户ID |
| created_at | datetime | 创建时间 |
| status | string | 批次状态 |
| total_files | integer | 文件总数 |
| success_count | integer | 成功数 |
| failed_count | integer | 失败数 |
| skipped_count | integer | 跳过数 |
| auto_analyze | boolean | 是否自动触发分析 |
| analyze_task_id | string | 关联的分析任务ID |

### 3.2 上传文件表 (upload_files)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 文件记录ID |
| batch_id | string | 所属批次ID |
| filename | string | 原始文件名 |
| file_size | integer | 文件大小（字节） |
| file_format | string | 文件格式（txt/md/docx/pdf/html） |
| status | string | 处理状态 |
| title | string | 提取的标题 |
| word_count | integer | 正文字数 |
| article_id | string | 关联素材ID |
| error_message | string | 错误信息 |
| content_hash | string | 文件内容前100字符MD5，用于去重 |
| original_file_url | string | 原始文件在对象存储中的路径（格式：uploads/{user_id}/{batch_id}/{filename}） |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

## 四、错误码

| 错误码 | 说明 |
|--------|------|
| 40700 | 上传模块通用错误 |
| 40701 | 批量上传总大小超过限制 |
| 40702 | 文件格式不支持 |
| 40703 | 没有有效的文档可供分析 |
| 40704 | 批次不存在 |
| 40705 | 文件内容重复 |
| 40706 | 文件解析失败 |
| 40707 | 文件编码异常，无法解码 |
| 40708 | 文件内容过短（少于50字符） |
| 40101 | 未认证（需登录后上传） |
| 40302 | 数据越权（访问他人上传批次） |
| 42902 | 上传配额超限（每日50个文件） |
