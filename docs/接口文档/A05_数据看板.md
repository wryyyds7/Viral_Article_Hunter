# 接口文档：数据看板

| 字段 | 内容 |
|------|------|
| 模块 | 数据看板 |
| 文档版本 | v1.0 |
| 更新日期 | 2026-06-04 |

> 所有接口遵循 [A00_公共接口规范](A00_公共接口规范.md) 的请求/响应格式和错误码规范。
> 所有看板接口均需认证（`Authorization: Bearer <access_token>`），看板数据基于用户私有数据生成。

---

## 一、接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /dashboard/today-hot | 获取今日TOP热文 |
| GET | /dashboard/trend | 获取热度趋势数据 |
| GET | /dashboard/topic-ranking | 获取话题热度排行 |
| GET | /dashboard/platform-comparison | 获取平台对比数据 |
| GET | /dashboard/wordcloud | 获取词云数据 |
| GET | /dashboard/creation-stats | 获取个人创作统计 |

---

## 二、接口详情

### 2.1 GET /dashboard/today-hot

获取今日各平台TOP热文卡片数据。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| platform | string | 否 | all | 平台筛选：all/xiaohongshu/wechat/toutiao/zhihu/bilibili |
| limit | integer | 否 | 5 | 每个平台返回数量，范围1-20 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.date | string | 数据日期 YYYY-MM-DD |
| data.last_updated_at | string | 最后更新时间 |
| data.items[] | HotArticle[] | 热文列表 |
| data.items[].rank | integer | 排名 |
| data.items[].id | string | 素材ID |
| data.items[].title | string | 标题 |
| data.items[].platform | string | 平台 |
| data.items[].hotness_score | integer | 热度评分 |
| data.items[].hotness_level | string | 评分等级 |
| data.items[].emotion_tags | EmotionTag[] | 情绪标签（仅主情绪） |
| data.items[].interaction | InteractionData | 互动数据 |
| data.is_empty | boolean | 今日是否无数据 |
| data.empty_hint | string | 空状态引导文案 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "date": "2026-06-04",
    "last_updated_at": "2026-06-04T11:00:00+08:00",
    "items": [
      {
        "rank": 1,
        "id": "article_001",
        "title": "世界杯转播权花落小红书！",
        "platform": "xiaohongshu",
        "hotness_score": 98,
        "hotness_level": "viral",
        "emotion_tags": [
          {"tag": "excitement", "display": "兴奋", "level": "strong", "is_primary": true, "category": "positive", "is_user_modified": false}
        ],
        "interaction": {
          "likes": 12500,
          "collects": 8900,
          "comments": 3200,
          "shares": null
        }
      }
    ],
    "is_empty": false,
    "empty_hint": null
  }
}
```

### 2.2 GET /dashboard/trend

获取热度趋势折线图数据。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| range | string | 否 | 7d | 时间范围：7d/30d/custom |
| start_date | string | 条件必填 | - | 自定义开始日期 YYYY-MM-DD（range=custom时必填） |
| end_date | string | 条件必填 | - | 自定义结束日期 YYYY-MM-DD（range=custom时必填，跨度≤90天） |
| platforms | string | 否 | 全部平台 | 逗号分隔平台列表 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.range | string | 时间范围 |
| data.dates | string[] | 日期数组（X轴） |
| data.series[] | TrendSeries | 各平台趋势数据 |
| data.series[].platform | string | 平台 |
| data.series[].display | string | 中文名 |
| data.series[].color | string | 图表颜色 |
| data.series[].values | float[] | 每日平均热度（与dates一一对应） |
| data.series[].counts | integer[] | 每日素材数量 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "range": "7d",
    "dates": ["2026-05-29", "2026-05-30", "2026-05-31", "2026-06-01", "2026-06-02", "2026-06-03", "2026-06-04"],
    "series": [
      {
        "platform": "xiaohongshu",
        "display": "小红书",
        "color": "#FF2442",
        "values": [72.5, 68.3, 75.1, 89.6, 82.4, 78.9, 85.2],
        "counts": [12, 10, 15, 22, 18, 14, 16]
      },
      {
        "platform": "wechat",
        "display": "公众号",
        "color": "#07C160",
        "values": [65.2, 62.1, 70.8, 76.3, 71.5, 68.2, 73.4],
        "counts": [8, 7, 11, 14, 10, 9, 12]
      }
    ]
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40501 | 数据不足（少于2天数据） |

### 2.3 GET /dashboard/topic-ranking

获取话题热度排行榜。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| range | string | 否 | 7d | 统计范围：7d/30d |
| limit | integer | 否 | 10 | 返回数量，范围1-30 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[].rank | integer | 排名 |
| data.items[].topic | string | 话题关键词 |
| data.items[].article_count | integer | 相关文章数 |
| data.items[].avg_score | float | 平均热度评分 |
| data.items[].composite_score | float | 综合得分（文章数×平均热度） |
| data.items[].trend | string | 趋势：up/down/stable |
| data.items[].trend_change | float | 趋势变化幅度 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "rank": 1,
        "topic": "世界杯",
        "article_count": 28,
        "avg_score": 85.3,
        "composite_score": 2388.4,
        "trend": "up",
        "trend_change": 12.5
      },
      {
        "rank": 2,
        "topic": "AI写作",
        "article_count": 15,
        "avg_score": 72.1,
        "composite_score": 1081.5,
        "trend": "stable",
        "trend_change": 1.2
      }
    ]
  }
}
```

### 2.4 GET /dashboard/platform-comparison

获取平台对比数据。支持两种模式：全局概览和同话题对比。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| mode | string | 否 | overview | 对比模式：overview（全局概览）/topic（同话题对比） |
| topic | string | 条件必填 | — | mode=topic时必填，话题关键词 |
| date_from | string | 否 | — | 起始日期 |
| date_to | string | 否 | — | 结束日期 |

**响应体（overview模式）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[].platform | string | 平台值 |
| data.items[].display | string | 中文名 |
| data.items[].total_articles | integer | 素材总量 |
| data.items[].avg_score | float | 平均评分 |
| data.items[].avg_likes | float | 平均点赞 |
| data.items[].avg_collects | float | 平均收藏 |
| data.items[].avg_comments | float | 平均评论 |
| data.items[].last_collected_at | string | 最近采集时间 |
| data.items[].is_stale | boolean | 是否数据过期（超3天） |

**响应示例（overview模式）：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "platform": "xiaohongshu",
        "display": "小红书",
        "total_articles": 80,
        "avg_score": 76.5,
        "avg_likes": 3500.2,
        "avg_collects": 2100.8,
        "avg_comments": 890.5,
        "last_collected_at": "2026-06-04T11:00:00+08:00",
        "is_stale": false
      },
      {
        "platform": "wechat",
        "display": "公众号",
        "total_articles": 45,
        "avg_score": 71.2,
        "avg_likes": 5200.1,
        "avg_collects": null,
        "avg_comments": 1560.3,
        "last_collected_at": "2026-06-01T09:00:00+08:00",
        "is_stale": true
      }
    ]
  }
}
```

**响应体（topic模式）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.topic | string | 话题关键词 |
| data.items[].platform | string | 平台 |
| data.items[].article_count | integer | 相关文章数 |
| data.items[].avg_score | float | 平均评分 |
| data.items[].top_emotion | string | 主要情绪 |
| data.items[].avg_interaction | InteractionData | 平均互动数据 |
| data.items[].top_title | string | 该平台该话题评分最高的标题 |

### 2.5 GET /dashboard/wordcloud

获取词云数据。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| range | string | 否 | 30d | 时间范围：7d/30d/all |
| limit | integer | 否 | 80 | 返回词数，范围10-200 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[].word | string | 词语 |
| data.items[].weight | float | 权重（频次×平均热度，用于字号映射） |
| data.items[].count | integer | 出现次数 |
| data.items[].avg_score | float | 关联素材平均热度 |
| data.items[].emotion_category | string | 情绪分类：positive/negative/mixed/neutral |
| data.items[].color | string | 推荐颜色（前端可覆盖） |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {"word": "世界杯", "weight": 2388.4, "count": 28, "avg_score": 85.3, "emotion_category": "positive", "color": "#FF6B35"},
      {"word": "裁员", "weight": 942.0, "count": 12, "avg_score": 78.5, "emotion_category": "negative", "color": "#4A90D9"},
      {"word": "AI写作", "weight": 1081.5, "count": 15, "avg_score": 72.1, "emotion_category": "mixed", "color": "#9B59B6"}
    ]
  }
}
```

### 2.6 GET /dashboard/creation-stats

获取个人创作统计数据。

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.total_generated | integer | 累计改写生成篇数 |
| data.platform_distribution[].platform | string | 平台 |
| data.platform_distribution[].count | integer | 该平台生成篇数 |
| data.platform_distribution[].percentage | float | 占比 |
| data.daily_trend.dates | string[] | 近7天日期 |
| data.daily_trend.counts | integer[] | 每日生成篇数 |
| data.most_used_params.colloquial | integer | 最常用口语化值 |
| data.most_used_params.emoji_density | integer | 最常用Emoji密度 |
| data.most_used_params.emotion_intensity | integer | 最常用情绪强度 |
| data.most_used_params.length | string | 最常用篇幅 |
| data.productive_day.date | string | 生成最多日期 |
| data.productive_day.count | integer | 该日生成篇数 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total_generated": 47,
    "platform_distribution": [
      {"platform": "xiaohongshu", "count": 22, "percentage": 46.8},

      {"platform": "douyin", "count": 10, "percentage": 21.3}
    ],
    "daily_trend": {
      "dates": ["2026-05-29", "2026-05-30", "2026-05-31", "2026-06-01", "2026-06-02", "2026-06-03", "2026-06-04"],
      "counts": [3, 5, 8, 12, 6, 7, 6]
    },
    "most_used_params": {
      "colloquial": 70,
      "emoji_density": 60,
      "emotion_intensity": 75,
      "length": "medium"
    },
    "productive_day": {
      "date": "2026-06-01",
      "count": 12
    }
  }
}
```
