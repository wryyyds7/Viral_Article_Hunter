# 接口文档：爆款基因分析

| 字段 | 内容 |
|------|------|
| 模块 | 爆款分析 |
| 文档版本 | v1.0 |
| 更新日期 | 2026-06-04 |

> 所有接口遵循 [A00_公共接口规范](A00_公共接口规范.md) 的请求/响应格式和错误码规范。

---

## 一、接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /analysis/articles/{article_id} | 获取单篇文章完整分析报告 |
| POST | /analysis/batch | 批量分析文章 |
| PUT | /analysis/articles/{article_id}/emotion-tags | 修正情绪标签 |
| PUT | /analysis/articles/{article_id}/title-formula | 修正标题公式 |
| GET | /analysis/title-formulas | 获取标题公式类型列表 |
| GET | /analysis/emotion-tags | 获取情绪标签类型列表 |
| GET | /analysis/structure-templates | 获取结构模板类型列表 |

---

## 二、接口详情

### 2.1 GET /analysis/articles/{article_id}

获取单篇文章的完整爆款分析报告。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| article_id | string | 文章/素材ID |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.article_id | string | 文章ID |
| data.title | string | 文章标题 |
| data.platform | string | 来源平台 |
| data.content | string | 原文内容 |
| data.summary | string | 摘要（200字内） |
| data.interaction | InteractionData | 互动数据 |
| data.analysis | AnalysisDetail | 分析详情 |
| data.analysis.version | integer | 分析版本号（修正后递增） |
| data.analysis.analyzed_at | string | 分析时间 |

**AnalysisDetail 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| hotness_score | HotnessScore | 热度评分 |
| title_formulas | TitleFormula[] | 标题公式列表 |
| emotion_tags | EmotionTag[] | 情绪标签列表 |
| structure_template | StructureTemplate | 结构模板 |

**HotnessScore 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| total | integer | 综合评分0-100 |
| level | string | 评分等级：viral/potential/average/low |
| dimensions.title_power | integer | 标题力0-100 |
| dimensions.emotion_density | integer | 情绪密度0-100 |
| dimensions.interaction_hook | integer | 互动钩子0-100 |
| dimensions.structure_density | integer | 结构密度0-100 |

**TitleFormula 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| type | string | 公式类型枚举 |
| display | string | 公式中文名 |
| confidence | float | 置信度0-1 |
| matched_text | string | 匹配到的原文片段 |
| is_user_modified | boolean | 是否被用户修正过 |

**EmotionTag 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| tag | string | 情绪标签枚举 |
| display | string | 中文名 |
| level | string | 强度：strong/medium/weak |
| is_primary | boolean | 是否为主情绪 |
| category | string | 分类：positive/negative/mixed |
| is_user_modified | boolean | 是否被用户修正过 |

**StructureTemplate 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| type | string | 模板类型枚举 |
| display | string | 中文名 |

| segments | Segment[] | 段落拆分 |
| segments[].role | string | 段落角色（引入/展开/高潮/总结等） |

### 2.2 POST /analysis/batch

批量触发文章分析。通常由采集完成后自动调用，也可手动触发。

**请求体：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| article_ids | string[] | 是 | — | 文章ID列表，最多50个 |
| force | boolean | 否 | false | 是否强制重新分析（已有分析结果的文章默认跳过） |

**请求示例：**

```json
{
  "article_ids": ["article_001", "article_002", "article_003"],
  "force": false
}
```

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.total | integer | 提交总数 |
| data.analyzed | integer | 已分析数（含跳过的已有结果） |
| data.queued | integer | 排队等待数 |
| data.skipped | integer | 跳过数（已有结果且force=false） |
| data.failed | integer | 失败数 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 3,
    "analyzed": 1,
    "queued": 2,
    "skipped": 0,
    "failed": 0
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40201 | article_ids为空 |
| 40202 | 超过50条限制 |

### 2.3 PUT /analysis/articles/{article_id}/emotion-tags

用户修正文章的情绪标签。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| article_id | string | 文章ID |

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| emotion_tags | EmotionTagInput[] | 是 | 修正后的情绪标签列表（全量覆盖） |

**EmotionTagInput 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| tag | string | 是 | 情绪标签枚举值 |
| level | string | 是 | 强度：strong/medium/weak |
| is_primary | boolean | 是 | 是否为主情绪（仅一个可为true） |

**请求示例：**

```json
{
  "emotion_tags": [
    {"tag": "excitement", "level": "strong", "is_primary": true},
    {"tag": "resonance", "level": "medium", "is_primary": false}
  ]
}
```

**响应体：**

返回修正后的完整分析报告（同 GET /analysis/articles/{article_id} 响应），修正的标签 `is_user_modified` 为 `true`，`version` 递增。

### 2.4 PUT /analysis/articles/{article_id}/title-formula

用户修正文章的标题公式。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| article_id | string | 文章ID |

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title_formulas | TitleFormulaInput[] | 是 | 修正后的标题公式列表（全量覆盖） |

**TitleFormulaInput 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 是 | 标题公式枚举值 |
| matched_text | string | 否 | 匹配的原文片段 |

**请求示例：**

```json
{
  "title_formulas": [
    {"type": "emotion", "matched_text": "好用到哭"},
    {"type": "number", "matched_text": ""}
  ]
}
```

**响应体：**

返回修正后的完整分析报告，修正的公式 `is_user_modified` 为 `true`，`version` 递增。
