# 接口文档：素材库管理

| 字段 | 内容 |
|------|------|
| 模块 | 素材库 |
| 文档版本 | v1.0 |
| 更新日期 | 2026-06-04 |

> 所有接口遵循 [A00_公共接口规范](A00_公共接口规范.md) 的请求/响应格式和错误码规范。
> 所有素材库接口均需认证（`Authorization: Bearer <access_token>`），素材库为用户私有数据。

---

## 一、接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /library/articles | 获取素材列表（搜索+筛选+分页） |
| GET | /library/articles/{article_id} | 获取素材详情（含完整分析） |
| PUT | /library/articles/{article_id}/tags | 修改素材标签 |
| PUT | /library/articles/{article_id}/favorite | 收藏/取消收藏 |
| DELETE | /library/articles/{article_id} | 删除单条素材 |
| POST | /library/articles/batch-tags | 批量打标签 |
| POST | /library/articles/batch-delete | 批量删除 |
| POST | /library/articles/batch-export | 批量导出 |
| GET | /library/tags | 获取标签云 |
| GET | /library/tags/suggest | 标签搜索建议 |
| GET | /library/stats | 获取素材库统计信息 |
| ~~POST~~ | ~~ /library/favorite-groups~~ | ~~创建收藏分组~~（v1.1预留） |
| ~~GET~~ | ~~/library/favorite-groups~~ | ~~获取分组列表~~（v1.1预留） |
| ~~PUT~~ | ~~/library/favorite-groups/{group_id}~~ | ~~重命名分组~~（v1.1预留） |
| ~~DELETE~~ | ~~/library/favorite-groups/{group_id}~~ | ~~删除分组~~（v1.1预留） |

## 二、接口详情

### 2.1 GET /library/articles

获取素材列表，支持多维度搜索和筛选。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| keyword | string | 否 | — | 搜索关键词（匹配标题+正文） |
| platforms | string | 否 | — | 平台筛选，逗号分隔（如xiaohongshu,wechat） |
| tags | string | 否 | — | 标签筛选，逗号分隔（如世界杯,体育） |
| emotion_tags | string | 否 | — | 情绪标签筛选，逗号分隔 |
| date_from | string | 否 | — | 起始日期 YYYY-MM-DD |
| date_to | string | 否 | — | 结束日期 YYYY-MM-DD |
| score_min | integer | 否 | 0 | 最低热度评分 |
| score_max | integer | 否 | 100 | 最高热度评分 |
| favorites_only | boolean | 否 | false | 仅显示收藏 |
| sort_by | string | 否 | hotness_score | 排序字段：hotness_score/collected_at/title_power/emotion_density |
| sort_order | string | 否 | desc | 排序方向：asc/desc |
| page | integer | 否 | 1 | 页码 |
| page_size | integer | 否 | 20 | 每页条数 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[] | ArticleSummary[] | 素材摘要列表 |
| data.pagination | Pagination | 分页信息 |
| data.facets | SearchFacets | 筛选面（用于渲染筛选器数量） |

**SearchFacets 结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| platforms[].platform | string | 平台值 |
| platforms[].count | integer | 该平台素材数 |
| emotion_tags[].tag | string | 情绪标签值 |
| emotion_tags[].count | integer | 该情绪素材数 |
| date_range.earliest | string | 最早采集日期 |
| date_range.latest | string | 最晚采集日期 |
| score_distribution | object | 评分分布 {0-49: n, 50-69: n, 70-89: n, 90-100: n} |

### 2.3 PUT /library/articles/{article_id}/tags

修改素材标签（全量覆盖自定义标签）。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| article_id | string | 素材ID |

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| custom_tags | string[] | 是 | 自定义标签列表，最多20个（含自动标签） |
| action | string | 否 | replace | 操作方式：replace(覆盖)/add(追加)/remove(移除) |

**请求示例：**

```json
{
  "custom_tags": ["重要", "待改写", "客户需求"],
  "action": "replace"
}
```

**响应体：**

返回修改后的完整 TagGroup。

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "auto_tags": ["世界杯", "体育", "足球"],
    "custom_tags": ["重要", "待改写", "客户需求"],
    "original_tags": ["世界杯", "小红书"]
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40401 | 素材不存在 |
| 40402 | 标签总数超过20个 |

### 2.4 PUT /library/articles/{article_id}/favorite

收藏或取消收藏素材。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| article_id | string | 素材ID |

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| is_favorited | boolean | 是 | true=收藏，false=取消收藏 |

**响应体：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "article_id": "article_001",
    "is_favorited": true
  }
}
```

### 2.6 POST /library/articles/batch-tags

批量给素材打标签。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| article_ids | string[] | 是 | 素材ID列表，最多50个 |
| tags | string[] | 是 | 要添加的标签列表 |
| action | string | 否 | add | 操作方式：add(追加)/remove(移除) |

**请求示例：**

```json
{
  "article_ids": ["article_001", "article_002", "article_003"],
  "tags": ["体育", "热点"],
  "action": "add"
}
```

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.success_count | integer | 成功数量 |
| data.failed_ids | string[] | 失败的ID列表 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "success_count": 3,
    "failed_ids": []
  }
}
```

| 字段 | 类型 | 说明 |

### 2.8 POST /library/articles/batch-export

批量导出素材。

**请求体：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| article_ids | string[] | 否 | — | 指定素材ID列表（与filter二选一） |
| filter | ExportFilter | 否 | — | 按条件导出（与article_ids二选一） |
| format | string | 否 | markdown | 导出格式：markdown/docx |
| include_analysis | boolean | 否 | true | 是否包含爆款分析 |

**ExportFilter 结构：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| platforms | string[] | 否 | 平台筛选 |
| tags | string[] | 否 | 标签筛选 |
| date_from | string | 否 | 起始日期 |
| date_to | string | 否 | 结束日期 |
| score_min | integer | 否 | 最低评分 |
| favorites_only | boolean | 否 | 仅收藏 |

**响应：**

文件下载流。单篇最大1000条素材。

| 格式 | Content-Type | 文件名 |
|------|-------------|--------|
| markdown | application/octet-stream | `素材库导出_{date}.md` |
| docx | application/vnd.openxmlformats-officedocument.wordprocessingml.document | `素材库导出_{date}.docx` |

### 2.9 GET /library/tags

获取标签云数据。

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| type | string | 否 | all | 标签类型：all/auto/custom/original |
| limit | integer | 否 | 50 | 返回数量，范围1-200 |
| date_from | string | 否 | — | 起始日期 |
| date_to | string | 否 | — | 结束日期 |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.items[].tag | string | 标签名称 |
| data.items[].count | integer | 使用次数 |
| data.items[].avg_score | float | 关联素材的平均热度评分 |
| data.items[].emotion_category | string | 主要情绪分类：positive/negative/mixed/neutral |
| data.items[].trend | string | 趋势：up/down/stable |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {"tag": "世界杯", "count": 28, "avg_score": 85.3, "emotion_category": "positive", "trend": "up"},

}
```
