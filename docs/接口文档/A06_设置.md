# 接口文档：设置

| 字段 | 内容 |
|------|------|
| 模块 | 设置 |
| 文档版本 | v1.0 |
| 更新日期 | 2026-06-04 |

> 所有接口遵循 [A00_公共接口规范](A00_公共接口规范.md) 的请求/响应格式和错误码规范。

---

## 一、接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /settings/api-keys | 获取API Key配置列表 |
| PUT | /settings/api-keys/{key_type} | 更新指定API Key |
| POST | /settings/api-keys/{key_type}/verify | 验证API Key有效性 |
| GET | /settings/rewrite-preferences | 获取改写偏好 |
| PUT | /settings/rewrite-preferences | 更新改写偏好 |
| POST | /settings/rewrite-preferences/reset | 重置为默认偏好 |
| POST | /settings/data/export | 导出数据备份 |
| POST | /settings/data/import | 导入数据备份 |
| POST | /settings/data/cleanup | 清理数据 |

---

## 二、接口详情

### 2.1 GET /settings/api-keys

获取所有API Key的配置状态（掩码显示）。

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.keys[].key_type | string | Key类型：honghu/llm |
| data.keys[].display_name | string | 显示名称 |
| data.keys[].masked_value | string | 掩码值（如sk-****xxxx） |
| data.keys[].status | string | 状态：valid/invalid/not_configured |
| data.keys[].last_verified_at | string | 最近验证时间 |
| data.keys[].is_required | boolean | 是否为必填Key |
| data.keys[].description | string | 用途说明 |
| data.keys[].configure_url | string | Key申请地址 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "keys": [
      {
        "key_type": "honghu",
        "display_name": "红狐数据API Key",
        "masked_value": "rh-****a1b2",
        "status": "valid",
        "last_verified_at": "2026-06-04T10:00:00+08:00",
        "is_required": false,
        "description": "用于采集小红书和公众号热文数据",
        "configure_url": "https://www.honghudata.com/api-key"
      },
      {
        "key_type": "llm",
        "display_name": "LLM API Key",
        "masked_value": "sk-****c3d4",
        "status": "valid",
        "last_verified_at": "2026-06-04T10:00:00+08:00",
        "is_required": true,
        "description": "用于爆款分析和内容改写",
        "configure_url": "https://platform.openai.com/api-keys"
      }
    ]
  }
}
```

### 2.2 PUT /settings/api-keys/{key_type}

更新指定类型的API Key。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| key_type | string | Key类型：honghu/llm |

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| value | string | 是 | API Key明文值，服务端加密存储 |
| base_url | string | 否 | 自定义API地址（仅llm类型） |

**请求示例：**

```json
{
  "value": "sk-abc123def456ghi789",
  "base_url": "https://api.openai.com/v1"
}
```

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.key_type | string | Key类型 |
| data.masked_value | string | 更新后的掩码值 |
| data.status | string | 验证状态 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "key_type": "llm",
    "masked_value": "sk-****i789",
    "status": "valid"
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40601 | Key类型无效 |
| 40602 | Key值为空 |
| 40603 | Key验证失败 |

---

### 2.3 POST /settings/api-keys/{key_type}/verify

验证API Key是否有效。

**路径参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| key_type | string | Key类型：honghu/llm |

**请求体：**

无需请求体，使用已保存的Key进行验证。

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.key_type | string | Key类型 |
| data.status | string | 验证结果：valid/invalid |
| data.message | string | 验证结果说明 |
| data.verified_at | string | 验证时间 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "key_type": "honghu",
    "status": "valid",
    "message": "API Key验证通过",
    "verified_at": "2026-06-04T11:50:00+08:00"
  }
}
```

**验证失败响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "key_type": "honghu",
    "status": "invalid",
    "message": "API Key无效或已过期",
    "verified_at": "2026-06-04T11:50:00+08:00"
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40601 | Key类型无效 |
| 40604 | Key未配置，无法验证 |

### 2.4 GET /settings/rewrite-preferences

获取当前改写偏好设置。

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.colloquial | integer | 口语化程度0-100 |
| data.emoji_density | integer | Emoji密度0-100 |
| data.emotion_intensity | integer | 情绪强度0-100 |
| data.length | string | 篇幅：short/medium/long |
| data.default_platforms | string[] | 默认目标平台列表 |
| data.is_default | boolean | 是否为系统默认值（未修改过） |
| data.updated_at | string | 最近更新时间 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "colloquial": 60,
    "emoji_density": 50,
    "emotion_intensity": 70,
    "length": "medium",
    "default_platforms": ["xiaohongshu", "wechat"],
    "is_default": false,
    "updated_at": "2026-06-04T11:30:00+08:00"
  }
}
```

---

### 2.5 PUT /settings/rewrite-preferences

更新改写偏好设置。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| colloquial | integer | 否 | 口语化程度0-100 |
| emoji_density | integer | 否 | Emoji密度0-100 |
| emotion_intensity | integer | 否 | 情绪强度0-100 |
| length | string | 否 | 篇幅：short/medium/long |
| default_platforms | string[] | 否 | 默认目标平台列表 |

> 仅传需要修改的字段，未传字段保持原值。

**请求示例：**

```json
{
  "colloquial": 75,
  "emoji_density": 65,
  "default_platforms": ["xiaohongshu", "wechat", "douyin"]
}
```

**响应体：**

返回更新后的完整偏好（同 GET 响应体），`is_default` 为 `false`。

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40605 | 参数值超出范围 |

---

### 2.6 POST /settings/rewrite-preferences/reset

重置改写偏好为系统默认值。

**请求体：**

无。

**响应体：**

返回重置后的完整偏好（同 GET 响应体），`is_default` 为 `true`。

### 2.7 POST /settings/data/export

导出完整数据备份。

**请求体：**

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| scope | string | 否 | all | 导出范围：all/articles_only/config_only |
| date_from | string | 否 | — | 起始日期（scope含articles时有效） |
| date_to | string | 否 | — | 结束日期 |

**请求示例：**

```json
{
  "scope": "all"
}
```

**响应体（异步导出）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.export_id | string | 导出任务ID |
| data.status | string | 状态：processing/completed |
| data.download_url | string | 下载地址（completed时） |
| data.expires_at | string | 下载链接过期时间 |
| data.file_size | integer | 文件大小（字节） |
| data.article_count | integer | 包含素材数 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "export_id": "export_20260604_001",
    "status": "completed",
    "download_url": "https://api.hotcontent-hunter.com/downloads/export_20260604_001.zip",
    "expires_at": "2026-06-05T11:50:00+08:00",
    "file_size": 2457600,
    "article_count": 156
  }
}
```

**导出ZIP结构：**

```
爆文猎人_备份_20260604.zip
├── manifest.json          ← 元信息（导出时间、版本、范围）
├── config.json            ← 配置备份（偏好、计划）
└── articles/              ← 素材数据
    ├── data.json          ← 全部素材结构化数据
    └── contents/          ← 原文Markdown文件
        ├── article_001.md
        └── article_002.md
```

**manifest.json 结构：**

```json
{
  "version": "1.0",
  "exported_at": "2026-06-04T11:50:00+08:00",
  "scope": "all",
  "article_count": 156,
  "includes_config": true,
  "app_version": "1.0.0"
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40606 | 导出数量超过1000条限制 |

### 2.8 POST /settings/data/import

导入数据备份。

**请求体：**

`Content-Type: multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | file | 是 | ZIP备份文件 |
| conflict_strategy | string | 否 | skip | 冲突策略：skip(跳过)/overwrite(覆盖) |

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.import_id | string | 导入任务ID |
| data.status | string | 状态：processing/completed/failed |
| data.imported_articles | integer | 导入素材数 |
| data.skipped_articles | integer | 跳过素材数（冲突） |
| data.overwritten_articles | integer | 覆盖素材数 |
| data.imported_config | boolean | 是否导入配置 |
| data.failed_reason | string | 失败原因（仅failed时） |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "import_id": "import_20260604_001",
    "status": "completed",
    "imported_articles": 150,
    "skipped_articles": 6,
    "overwritten_articles": 0,
    "imported_config": true,
    "failed_reason": null
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40607 | 文件格式不正确（非ZIP或非本系统导出） |
| 40608 | manifest.json缺失或版本不兼容 |
| 40609 | 数据校验失败（文件损坏） |

### 2.9 POST /settings/data/cleanup

清理数据。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mode | string | 是 | 清理模式：by_date/by_platform/all |
| date_from | string | 条件必填 | mode=by_date时必填 |
| date_to | string | 条件必填 | mode=by_date时必填 |
| platforms | string[] | 条件必填 | mode=by_platform时必填，平台列表 |
| confirm_text | string | 条件必填 | mode=all时必填，必须为"确认清空" |

**请求示例（按日期清理）：**

```json
{
  "mode": "by_date",
  "date_from": "2026-05-01",
  "date_to": "2026-05-31"
}
```

**请求示例（全部清空）：**

```json
{
  "mode": "all",
  "confirm_text": "确认清空"
}
```

**响应体：**

| 字段 | 类型 | 说明 |
|------|------|------|
| data.mode | string | 清理模式 |
| data.deleted_count | integer | 已删除素材数 |
| data.freed_bytes | integer | 释放空间（字节） |
| data.completed_at | string | 完成时间 |

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "mode": "by_date",
    "deleted_count": 42,
    "freed_bytes": 1048576,
    "completed_at": "2026-06-04T11:50:05+08:00"
  }
}
```

**特殊错误码：**

| 错误码 | 说明 |
|--------|------|
| 40610 | 清理模式无效 |
| 40611 | 日期范围缺失 |
| 40612 | 平台列表缺失 |
| 40613 | 确认文本不匹配（mode=all时必须输入"确认清空"） |
