# A08 管理后台接口

| 字段 | 内容 |
|------|------|
| 模块编号 | A08 |
| 模块名称 | 管理后台 |
| 基础路径 | `/v1/admin` |
| 权限要求 | **所有接口需 AdminOnly 中间件校验**（role = 'admin'） |
| 关联文档 | F08_管理后台.md、A00_公共接口规范.md |

> 所有管理后台接口公共请求头：
> - `Authorization: Bearer <access_token>` — 必须
> - `x-session: <session_token>` — 必须
> - 后端中间件校验 token 对应用户 role=admin，否则返回 40301

## 1. 用户管理

### 1.1 获取用户列表

```
GET /v1/admin/users
```

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认1 |
| page_size | int | 否 | 每页条数，默认20，最大50 |
| keyword | string | 否 | 搜索关键词（匹配昵称/邮箱） |
| role | string | 否 | 角色筛选：user / admin |
| status | string | 否 | 状态筛选：active / disabled |
| registered_after | string | 否 | 注册时间起点（ISO 8601） |
| registered_before | string | 否 | 注册时间终点（ISO 8601） |

**响应体**：

```json
{
  "code": 0,
  "data": {
    "total": 156,
    "page": 1,
    "page_size": 20,
    "items": [
      {
        "id": "uuid",
        "email": "user@example.com",
        "nickname": "小明",
        "role": "user",
        "status": "active",
        "total_analyses": 42,
        "total_rewrites": 28,
        "total_uploads": 15,
        "created_at": "2026-06-01T10:00:00+08:00",
        "last_login_at": "2026-06-04T15:30:00+08:00"
      }
    ]
  }
}
```

### 1.3 封禁用户

```
POST /v1/admin/users/{user_id}/ban
```

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| reason | string | 是 | 封禁原因，1-200字符 |

**响应体**：

```json
{
  "code": 0,
  "data": {
    "id": "uuid",
    "status": "disabled",
    "banned_at": "2026-06-04T16:00:00+08:00",
    "reason": "滥用API，单日改写超过500次"
  }
}
```

**副作用**：
- 该用户所有 refresh_token 立即撤销
- 该用户进行中的异步任务终止
- 操作写入 admin_audit_log

### 1.4 解封用户

```
POST /v1/admin/users/{user_id}/unban
```

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| reason | string | 否 | 解封原因 |

**响应体**：

```json
{
  "code": 0,
  "data": {
    "id": "uuid",
    "status": "active",
    "unbanned_at": "2026-06-04T17:00:00+08:00"
  }
}
```

### 1.5 变更用户角色

```
POST /v1/admin/users/{user_id}/role
```

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| role | string | 是 | 目标角色：user / admin |
| reason | string | 是 | 变更原因 |

**响应体**：

```json
{
  "code": 0,
  "data": {
    "id": "uuid",
    "role": "admin",
    "changed_at": "2026-06-04T18:00:00+08:00"
  }
}
```

**业务规则**：
- 不能降低自己的角色
- 至少保留一个管理员
- 变更后该用户需重新登录获取新 Token

### 1.6 删除用户

```
DELETE /v1/admin/users/{user_id}
```

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| confirm | string | 是 | 必须输入 "DELETE" 确认 |

**响应体**：

```json
{
  "code": 0,
  "data": {
    "id": "uuid",
    "deleted_at": "2026-06-04T19:00:00+08:00",
    "data_retention_until": "2026-07-04T19:00:00+08:00"
  }
}
```

**业务规则**：
- 软删除，用户 status 改为 'deleted'
- 关联数据保留30天后由定时任务清理
- 不能删除自己

## 6. 系统配置

### 6.1 获取当前配置

```
GET /v1/admin/config
```

**响应体**：

```json
{
  "code": 0,
  "data": {
    "upload_threshold": 10,
    "collect_rate_limit": 10,
    "rewrite_rate_limit": 5,
    "upload_rate_limit": 5,
    "llm_model": "deepseek-chat",
    "llm_temperature": 0.7,
    "llm_max_tokens": 4096,
    "maintenance_mode": false,
    "content_review_enabled": true
  }
}
```

### 6.2 更新配置

```
PUT /v1/admin/config
```

**请求体**：需要更新的字段即可，未传的字段保持不变。

| 字段 | 类型 | 说明 |
|------|------|------|
| upload_threshold | int | 5-50 |
| collect_rate_limit | int | 1-60 |
| rewrite_rate_limit | int | 1-30 |
| upload_rate_limit | int | 1-30 |
| llm_model | string | 可选模型名 |
| llm_temperature | float | 0.0-1.0 |
| llm_max_tokens | int | 1024-8192 |
| maintenance_mode | bool | 维护模式 |
| content_review_enabled | bool | 内容审核开关 |

**响应体**：返回更新后的完整配置（同 6.1 格式）

**副作用**：
- 配置变更实时生效
- 所有变更记录写入 admin_audit_log
- maintenance_mode 变更时广播事件通知所有在线用户

## 8. 错误码

| 错误码 | HTTP | 说明 |
|--------|------|------|
| 40301 | 403 | 无权限访问（通用：非管理员访问管理后台时触发） |
| 40302 | 403 | 数据越权访问（通用） |
| 40303 | 403 | 账户已禁用（通用） |
| 40801 | 400 | 封禁原因不能为空 |
| 40802 | 400 | 角色变更原因不能为空 |
| 40803 | 400 | 无效的角色值 |
| 40804 | 400 | 删除确认文本不匹配 |
| 40805 | 409 | API Key 仍被采集任务依赖，无法删除 |
| 40806 | 400 | 配置值超出允许范围 |
| 40807 | 400 | 违规原因不能为空 |
| 40808 | 409 | 用户已被封禁，无需重复操作 |
| 40809 | 403 | 不能降低自己的管理员角色 |
| 40810 | 403 | 不能删除自己 |
| 40811 | 403 | 系统至少保留一个管理员 |
